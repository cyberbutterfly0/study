## 四、项目结构

```text
zhiwei-cloud/
├── pom.xml                                  # 父 POM：版本管理 + BOM 导入 + 模块聚合
├── zhiwei-dependencies/                     # 依赖版本管理（BOM）
├── zhiwei-framework/                        # 框架封装（聚合）
│   ├── zhiwei-common/                       # 通用工具、常量、异常
│   ├── zhiwei-spring-boot-starter-web/      # Web 封装：统一返回、全局异常、i18n、TraceId
│   ├── zhiwei-spring-boot-starter-mybatis/  # MyBatis-Plus 封装
│   ├── zhiwei-spring-boot-starter-redis/    # Redis 封装
│   ├── zhiwei-spring-boot-starter-security/ # 安全封装
│   └── zhiwei-spring-boot-starter-biz-tenant/ # 多租户封装
├── zhiwei-gateway/                          # API 网关（启动入口之一）
├── zhiwei-module-system/                    # 系统模块：用户、角色、菜单、租户
│   ├── zhiwei-module-system-api/            # 接口定义（DTO、Feign Client）
│   └── zhiwei-module-system-server/         # 服务实现（启动入口）
├── zhiwei-module-infra/                     # 基础设施模块：文件、日志、定时任务
│   ├── zhiwei-module-infra-api/
│   └── zhiwei-module-infra-server/
├── zhiwei-module-pay/                       # 支付模块
├── zhiwei-module-wx/                        # 微信模块
├── zhiwei-module-member/                    # 会员模块
└── zhiwei-module-booking/                   # 预约模块
```

## 五、模块依赖关系

```text
zhiwei-dependencies (BOM：只管版本，不写代码)
        │ 所有模块 import 它
        ▼
zhiwei-framework 的各 starter
        │ 业务模块依赖
        ▼
zhiwei-module-xxx-server  ──────►  注册到 Nacos
        │                              ▲
        │ 依赖 api 模块（Feign 调用）    │ 网关转发
        ▼                              │
zhiwei-module-xxx-api         zhiwei-gateway ──► 客户端
```

要点：

- `-api` 只放接口和 DTO，不放实现，避免循环依赖
- `-server` 是真正的服务，有 `Application` 启动类
- 网关统一入口，客户端不直连服务
- 版本统一在 `zhiwei-dependencies` 里管，业务模块不写版本号

## 六、快速开始

环境要求：

- JDK 27+
- Maven 3.9+
- Docker（起 MySQL / Redis / Nacos）

```bash
# 构建（跳过测试）
mvn clean install -DskipTests

# 起中间件
docker compose up -d

# 启动各个服务（每个模块单独起，或 IDEA 里点 Run）
mvn spring-boot:run -pl zhiwei-module-system/zhiwei-module-system-server
```

## 九、创建 Maven 多模块工程

1. 右键 `zhiwei-cloud` → **New → Module**
2. 左侧选 **Maven Archetype**
3. Name 填模块名，比如 `zhiwei-dependencies`
4. Archetype 选 `org.apache.maven.archetypes:maven-archetype-quickstart`
5. JDK 选 27（没有就 25）
