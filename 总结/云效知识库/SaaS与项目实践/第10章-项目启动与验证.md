# 第10章 项目启动与验证

前提：中间件已起（第 4 章 `docker compose up -d`），`mvn clean install -DskipTests` 已构建通过。

## 一、IDEA 里启动

1. 打开 `zhiwei-gateway → src/main/java → cloud.zhiwei.gateway → GatewayApplication`
2. 右键这个类，点绿色箭头 **Run**
3. **第一次会报错，先不管**——它会生成一个运行配置
4. 打开顶部下拉框旁边的 **Edit Configurations...**
5. 找到 `GatewayApplication`，在 **Environment variables** 里填：

```text
spring.profiles.active=dev
```

6. 点 **OK**，再 Run 一次

这样网关就以 dev 环境启动了。

## 二、验证三个地址

服务起来后，浏览器或 Postman 访问：

| 验证什么 | 地址 |
|---|---|
| 直连 system 服务 | http://localhost:48081/api/system/health |
| 走网关访问 | http://localhost:48080/zhiwei-system-server/api/system/health |
| Feign 跨服务调用 | http://localhost:48082/api/infra/call-system |

三个都能出正常返回，说明：服务注册、网关路由、服务间调用三件事都通了。
