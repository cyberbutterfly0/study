# 总结文件夹

这个文件夹是**学习档案**，不是给我的答复。里面的内容由工作区 skill 在每次辅导后增量更新：一般学习走 `study-tutor`，**STM32 / 单片机 / 智能车走 `stm32-tutor`**（这个领域是讲授式，规则不一样，见下）。

## 怎么用

- 你就正常提问，我先判断问题类型再决定怎么答：
  - **概念 / 推理 / 设计 / 调试类**（"为什么……"、"该怎么设计"）：默认**只给提示、不给答案**，按三级展开 L1 方向 → L2 定位 → L3 关键点，追问一次展开一级。
  - **操作 / 事实类**（软件怎么用、在哪设置、装哪个版本、这个报错什么意思）：**直接给结论和步骤**，不摆引导架子、不反问。这类答案进 `软件使用/软件使用.md` 的速查表，不建主题档案、不画图。
  - **拿不准**：我会先问一句"你想直接要答案，还是走提示"，不猜。
  - **STM32 / MSPM0 / 单片机 / 智能车**：**例外**。这个领域是从零系统学，不套三级提示，而是讲授式——一轮一小节，讲透 → 出题 → 给实践任务，答错当天进错题本，每章学完补「本章易错点」和「本章小结」。两套平台并行学，原理讲一篇、两侧各看一遍怎么落地。内容进 `单片机-智能车/`。
- 想直接要答案时，明确说「直接给我答案」或「别提示了」——这时才跳过提示直接给，但相关原理仍会补进本文件夹。
- 每轮结束后我会把知识点、前置依赖、易错点和你的提问记录写进对应文档。概念类进 `<主题>/<主题>.md`，操作类进 `软件使用/软件使用.md`。
- 要找东西：先看 [INDEX.md](./INDEX.md)（脚本生成，一眼看到每个主题学到哪、卡住几个问题），或者直接在 `总结/` 里全文搜索。

## 目录结构

```
总结/
  INDEX.md              索引 + 各主题状态（脚本生成，勿手改）
  README.md             本文件
  _阅读版/               上面所有 .md 的 HTML 阅读版（浏览器直接打开，脚本生成，勿手改）
  _暂存/
    未归档.md           还凑不成主题的零散知识点（下划线开头，索引会跳过）
  软件使用/
    软件使用.md          操作/事实类问题的速查表（结论+步骤+一句原理+坑），不画图
  单片机-智能车/         单片机软件（讲授式，章节型结构，STM32 + MSPM0 双平台）
    单片机-智能车.md     总览：目标 / 学习方式 / 章节清单 / 进度表 / 已掌握基线
    平台对照.md          同一个概念在两套平台上的叫法与写法对照
    第N章-<章名>.md      每章：小节讲解、选择题、实践任务、本章易错点、本章小结
    错题本.md            答错的题：题目 / 我选 / 正确 / 错因 / 正确思路
  <主题>/
    <主题>.md            主文档：概览 / 已掌握基线 / 概念卡 / 前置依赖 / 易错点 / 提问记录
    图/
      <知识点-知识点-...>.html   知识链图，一张图一个文件，名字写清是哪条链
      <同名>.def.json           这张图的结构定义（要改图就改它再重生成），可删
```

- 下划线开头的目录（`_阅读版`、`_暂存`）都是辅助产物或临时区，不算主题、不进 `INDEX.md`。
- 两种文档分工：`软件使用/软件使用.md` 装**操作/事实类**问题（怎么用、在哪点、什么命令），直接给答案；`<主题>/<主题>.md` 装**概念/推理类**问题，走提示引导。别混。
- `INDEX.md` 表格里的「概念卡」列对 `软件使用` 显示的是速查条目数，「提问」列只统计概念类的提问记录，看的时候按这个理解。
- 主题目录名具体到范围：`Java-集合框架`、`Java-并发`、`HTTP-缓存`，不是笼统的 `Java`。
- 图文件名写清是哪条链：`equals-hashCode-取值链.html`。一个主题可以有多张图；知识点之间没关联就不硬画进同一张图，留在主文档概念卡里就行。
- **分类原则**：只有知识点之间能互相解释、互为因果（能用「因为 A 所以 B」连起来）才放进同一个主题目录。同一门语言、同一个工具不算关联——宁可多几个小而准的目录，也不要一个大目录装不相关的东西。相关主题之间用文字互链，不合并。
- 单独一个问题暂时成不了链，先记到 `_暂存/未归档.md`，同领域攒到 2–3 条再提升为正式主题。

分节模板与字段规则见 `E:\dsh结算\study\.dsh\skills\study-tutor\references\summary-format.md`。字段名改了索引脚本就统计不到，别改。

## 看不了 .md 文件？

这台机器上 `.md` 没有关联任何程序，双击打不开。三种办法：

1. **用浏览器看**（推荐，零安装）：打开 `E:\dsh结算\study\总结\_阅读版\index.html`，里面是全部档案的 HTML 阅读版，链接都能互相点。改完 `.md` 后重跑一次刷新（在 PowerShell 里执行）：`pwsh -File "E:\dsh结算\study\.dsh\skills\study-tutor\scripts\build-reader.ps1"`

2. **用 VS Code 看**：已装（`E:\vs code\Microsoft VS Code\bin\code.cmd`）。右键 `.md` 文件 → 打开方式 → 更多应用 → 选 VS Code，勾上"始终使用此应用"；也可以在 VS Code 里按 `Ctrl+Shift+V` 看渲染后的效果。

3. **让 `.md` 双击就是预览**：需要装个 Markdown 编辑器（Typora / Obsidian / MarkText）。这个我没动，要的话告诉我。
