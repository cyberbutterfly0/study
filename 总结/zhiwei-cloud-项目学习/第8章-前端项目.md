# 第8章 前端项目

## 一、前端在哪、有几套

前端都在 `zhiwei-frontend/` 下，是**两个独立的 workspace**：

```text
zhiwei-frontend/
├── zhiwei-ui-admin/        管理端（Vue Vben Admin V5，monorepo）
│   └── apps/web-tdesign/   ← 实际跑的就是这个应用
├── apps/
│   ├── zhiwei-ui-work/     工作端（yudao-ui-admin-uniapp，待初始化）
│   └── zhiwei-ui-app/      用户端（待初始化）
├── packages/
│   └── zhiwei-ui-shared/   用户端/工作端/管理端共享包
├── AGENTS.md
└── INIT.md                 知微前端初始化指南
```

管理端不是普通 Vue 项目，是 **vben-admin 5.7.0 的 monorepo**（仓库根 `zhiwei-ui-admin/package.json` 的 name 是 `vben-admin-monorepo`），`apps/web-tdesign` 才是真正的管理后台应用。所以启动命令要带 `-F @vben/web-tdesign`，或者用根 package.json 里封装好的 `dev:tdesign` 脚本。

## 二、环境要求

| 工作区 | Node.js | pnpm | 用途 |
|---|---|---|---|
| `zhiwei-frontend/` | ≥20 | ≥9 | 用户端 + 工作端 + 共享包 |
| `zhiwei-frontend/zhiwei-ui-admin/` | ≥22.18.0 | ≥11 | 管理端 |

本机实测：Node **v24.21.0**、pnpm **11.22.0**，都够用。pnpm 的 registry 已指向 `https://registry.npmmirror.com`。

## 三、启动管理端

### 命令行方式（推荐）

```powershell
cd E:\study\zhiwei-cloud\zhiwei-frontend\zhiwei-ui-admin

# 首次：安装依赖（几百个包，5~15 分钟正常）
pnpm install

# 启动开发服务器
pnpm dev:tdesign
```

`pnpm dev:tdesign` 等价于 `pnpm -F @vben/web-tdesign run dev`。

启动成功后在浏览器打开 **http://localhost:5173**。

### IDEA 方式（负责人截图里的那种）

1. 运行 → 编辑配置 → `+` → **npm**
2. package.json：选 `E:\study\zhiwei-cloud\zhiwei-frontend\zhiwei-ui-admin\package.json`
3. 命令：`run`
4. 脚本：`dev:tdesign`
5. Node 解释器：选 Node 24（本机 v24.21.0）
6. 确定 → 点绿色 ▶ 运行

## 四、必须注意的几点

- **只能用 pnpm**。`zhiwei-ui-admin/package.json` 里有 `"preinstall": "npx only-allow pnpm"`，用 `npm install` 会直接报错退出。
- **先起后端再开前端**。登录接口走网关/system 服务，后端没起，前端页面能开但登录会失败。后端启动见第 2 章。
- **首次 install 会跑 postinstall 和 prepare**（`pnpm -r run stub`、`lefthook install`），出现相关 warning 一般可忽略。
- 依赖没装时 `node_modules` 不存在，`pnpm dev:tdesign` 会报找不到 vsh/turbo 之类，先跑 `pnpm install`。
