# 第1章 模块结构与端口

## 一、分层

```text
根 pom（版本管理 + BOM 导入 + 模块聚合）
├── zhiwei-dependencies       BOM 模块，统一依赖版本，可对外发布
├── zhiwei-framework          公共框架聚合（不独立启动）
│   ├── zhiwei-common                       最底层：Ret 统一返回、ErrorCode、ServiceException、Args 校验、ZhiWeiJson
│   ├── zhiwei-spring-boot-starter-web      Web 层：全局异常、i18n、traceId
│   ├── zhiwei-spring-boot-starter-mybatis
│   ├── zhiwei-spring-boot-starter-redis
│   ├── zhiwei-spring-boot-starter-security 认证鉴权 + 操作日志拦截器（11-06 新增）
│   └── zhiwei-spring-boot-starter-biz-tenant
├── zhiwei-gateway            API 网关（可独立启动）
├── zhiwei-module-system      系统管理：用户/角色/菜单/权限/租户/字典
├── zhiwei-module-infra       基础设施：文件存储/参数配置/操作日志
├── zhiwei-module-pay         支付（骨架）
├── zhiwei-module-member      会员（骨架）
├── zhiwei-module-booking     预约（骨架）
├── zhiwei-module-wx          微信（骨架）
└── zhiwei-module-mall        商城（骨架）
```

根目录还有几个**不是 Maven 模块**的顶层条目：

| 条目 | 是什么 |
|---|---|
| `zhiwei-frontend/` | 前端 monorepo（vben 管理端 + uniapp 工作端/用户端）。**2026-11-06 起已拆成独立 Git 仓库**，父仓库不再跟踪，本地目录还在但 `git pull` 不会更新它（见第 8 章） |
| `zhiwei-ai-governance/` | AI 治理/开发规范文档：`standards/` 17 篇 + `workflows/` 4 个 + `checklists/` 3 个 + `decisions/` 4 个 + `scripts/` 5 个检查脚本，不参与构建（见第 9 章） |
| `sql/` | 数据库脚本：`nacos-mysql-schema.sql`、`template_biz_table.sql`、`base/` 6 个按日期命名的成套脚本、`system/` 索引修复脚本（见第 3 章） |
| `.env.example` | 环境变量模板。**`.env` 本身已被移出版本控制**（`0d75bc6`），新环境从示例复制一份（见第 4 章） |
| `lefthook.yml` | git hooks 配置（前端 install 时会装） |

## 二、约定

- 业务模块是**聚合模块**（packaging=pom）
- 子模块两个：
  - `<parent>-api`：DTO + Feign 接口，被别的模块依赖
  - `<parent>-server`：Controller / Service / Mapper，可独立启动

## 三、端口

| 服务 | 端口 | 说明 |
|---|---|---|
| zhiwei-gateway | 48080 | 网关，所有请求入口 |
| zhiwei-system-server | 48081 | 系统管理 |
| zhiwei-infra-server | 48082 | 基础设施 |
| Nacos Server | 8848 | 容器，OpenAPI（3.x 不再提供管理界面） |
| Nacos 客户端 | 9848 | 容器 gRPC |
| Nacos 控制台 | 8080（本地映射 18080） | 容器，3.x 独立出来的 Console 端口；本机把 8080 让给别人，所以映射成 18080 |
| Redis | 6379 | 容器 |

网关和业务服务统一在 4808x 段，避开 8080。

## 四、实际版本 vs 云效文档

对着根 `pom.xml` 核过，**有几处和云效《项目架构》写的对不上**，以代码为准：

| 组件 | 云效文档写 | 根 pom 实际 |
|---|---|---|
| Spring Boot | 4.1.1 | **4.1.2** |
| Spring Cloud Gateway | 4.3.0 | **5.0.3**（WebFlux 版） |
| Nacos 服务端 | 3.1.1（后来负责人升到 3.3，带 AI MCP） | `docker-compose.yml` 里是 **`nacos/nacos-server:v3.3.0-RC`**；客户端 3.1.1 |
| 模块 | 未提 mall | **多了 zhiwei-module-mall** |

其余一致：JDK 27、Spring Cloud 2025.1.3、SCA 2025.1.0.0、MyBatis-Plus **3.5.18**、Druid 1.2.28、Redisson 4.8.0、Lombok 1.18.48、MapStruct **1.6.3**、Hutool 5.8.48、SpringDoc 3.1.1 + Knife4j 4.5.0、Logback 1.6.5。
