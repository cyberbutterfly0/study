# 英语速查（编程 / 业务常用）

> 用途：英语底子薄时的查表页。不背单词表，遇到不认识的词来这里搜，看清「它在你项目里出现在哪」，再回去看代码。
> 一句话原则：**不需要读得准，需要看到能认出来。**
> 维护方式：每轮提问里出现新词，往对应表里补一行；重复出现的词在「出现位置」里补项目路径。

---

## 1. 增删改查（CRUD）

编程里最核心的四个动词，几乎所有接口、按钮、菜单都围着它们转。

| 词 | 读音（谐音） | 意思 | 项目里在哪 |
|---|---|---|---|
| Create | 克瑞-艾特 | 新增 | `POST /api/member/info/create`、库里 `INSERT` |
| Read | 瑞德 | 查询（读） | `GET /page`、`GET /get`、库里 `SELECT` |
| Update | 阿普-戴特 | 修改 | `POST /update`、库里 `UPDATE` |
| Delete | 迪-利特 | 删除 | `POST /delete`、库里 `DELETE`（我们是逻辑删除，只改 `deleted` 字段） |

四个词首字母拼起来就是 **CRUD**（常读作「克拉德」），说「一个 CRUD 模块」就是「增删改查模块」。

## 4. 报错信息里的高频词

看到报错先在这张表里找关键词，再去查具体原因。

| 报错片段 | 意思 | 你项目里出现过 |
|---|---|---|
| `Access denied` | 拒绝访问（账号密码 / 白名单不对） | 连阿里云库报 1045 |
| `using password: YES` | 这次连接带了密码 | 同上 |
| `Connection refused` | 连接被拒（端口没开 / 地址不对） | Nacos 连不到 MySQL |
| `Communications link failure` | 通信链路失败（连不上） | 同上 |
| `Unknown column` | 数据库没有这个列 | 表结构没同步 |
| `Table ... doesn't exist` | 表不存在 | SQL 脚本没跑 |
| `Duplicate entry` | 重复数据（唯一键冲突） | 重复 `member_no` |
| `Not Found` / `资源不存在` | 查不到 | 改已删除的记录 |
| `Unauthorized` / 401 | 没带 Token 或 Token 过期 | 未登录调接口 |
| `Forbidden` / 403 | 有 Token 但没这个权限 | 权限码没授权 |
| `NullPointerException` | 空指针（拿 null 去用了） | 代码 bug |
| `ClassNotFoundException` | 找不到类（依赖没进来） | jar 缺失 |
| `No implementation was created` | MapStruct 没生成实现类 | 注解处理器没跑 |
| `Failed to execute goal` | Maven 某个插件执行失败 | 门禁 / 编译 |
| `BUILD FAILURE` | 构建失败 | 看上面第一条 ERROR |
| `Compilation failure` | 编译失败 | 看上面的 ERROR 行 |
| `Port ... was already in use` | 端口被占 | 48082 重复启动 |
| `Cannot resolve symbol` | 找不到符号（类/变量不存在） | 路径错、jar 没引 |
| `denied` / `permission denied` | 被拒绝 | 沙箱、文件权限 |
| `timeout` | 超时 | 网络、锁 |

## 8. 记忆方法（比背单词管用）

1. **先认「词根」**：`pre-` 前、`post-` 后、`re-` 再、`un-` 不、`in-` 进、`out-` 出、`sub-` 下、`multi-` 多。看到 `preview`（预-看）、`refresh`（再-新鲜）。
2. **编程英语 80% 是「动词 + 名词」**：`create`（动词）+ `MemberInfo`（名词）= 创建会员信息。拆开就懂。
3. **一词多义按场景记**：`field` 在数据库是「字段」，在表单里是「输入框」；`header` 是「请求头」，不是「头」。
4. **不认识的词先在报错里找**：报错第一行往往就是关键词，把它抄进第 5 节，下次直接认。
5. **不要让读音拦住你**：代码里没人读，只有人看。先做到「看到认识」，读音会自己跟上。
