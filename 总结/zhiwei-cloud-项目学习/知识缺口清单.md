## 1. Java 语言本身

| 概念 | 英文 | 一句话 | 状态 |
|---|---|---|---|
| 注解 | Annotation | `@` 开头的东西，本身不执行逻辑，是给编译器/框架看的标记 | ✅ |
| 接口 | interface | 只声明方法、没有方法体；要靠实现类补上 | ✅ |
| 实现 | implements | 一个类答应「照着接口的声明把方法写出来」 | ✅ |
| 继承 | extends | 子类直接获得父类的字段和方法 | ✅ |
| 包 | package | Java 的目录分组，包名必须和目录结构一致 | ✅ |
| 动态代理 | dynamic proxy | 运行时在内存里生成的类，接口没有方法体也能被调用 | ✅ |
| 泛型 | generics | `<T>`、`Ret<Void>`、`List<MemberInfo>` 里的尖括号部分 | ⬜ |
| 枚举 | enum | 一组固定常量（如状态码），项目里用 Integer + 常量替代 | ⬜ |
| 日期时间 | LocalDate / LocalDateTime | 新的日期/时间类型，替代老的 `java.util.Date` | ⬜ |
| 序列化 | serialization | 对象 ↔ 字节流/JSON 的转换 | ⬜ |

## 2. Spring 框架

| 概念 | 英文 | 一句话 | 状态 |
|---|---|---|---|
| 控制反转 / 依赖注入 | IoC / DI | 对象不自己 new，由 Spring 创建并塞进来（`@Autowired`） | ⬜ |
| Bean | Bean | 被 Spring 管理的对象 | ⬜ |
| 控制器 | `@RestController` + `@RequestMapping` | 对外暴露 HTTP 接口的类 | ✅ |
| 路由注解 | `@GetMapping` / `@PostMapping` | 把 URL + HTTP 方法绑到某个方法上 | ✅ |
| 请求体 | `@RequestBody` | 把 HTTP 请求里的 JSON 变成 Java 对象 | ✅ |
| 查询参数 | `@RequestParam` | 从 `?id=1` 这种查询串里取参数 | ✅ |
| 参数校验 | `@Valid` + `@NotBlank` / `@Size` | 进方法前先检查参数合法性 | ✅ |
| 事务 | `@Transactional` | 一组数据库操作要么全成功、要么全回滚 | ⬜ |
| 方法级权限 | `@PreAuthorize` | 调这个方法前先检查当前用户有没有权限码 | ⬜ |
| 自动配置 | auto-configuration | Spring Boot 按 classpath 里的 jar 自动装配功能 | ⬜ |
| 配置导入 | `spring.config.import` | 让 yml 去读 `.env` / Nacos 里的配置 | ⬜ |

## 3. Spring Cloud / 微服务

| 概念 | 英文 | 一句话 | 状态 |
|---|---|---|---|
| 注册中心 | Nacos | 服务启动后把自己登记进去，别的服务按名字找得到它 | ⬜ |
| 配置中心 | Nacos Config | 把配置放远端，改完不用重启 | ⬜ |
| 服务调用 | Feign / `@FeignClient` | 像调本地方法一样调另一个服务的 HTTP 接口 | ✅ |
| 网关 | Gateway | 所有外部请求的唯一入口，按路径转发给具体服务 | ✅ |
| 负载均衡 | LoadBalancer | 同一个服务有多个实例时，挑一个发请求 | ⬜ |

## 4. MyBatis-Plus / 数据库访问

| 概念 | 英文 | 一句话 | 状态 |
|---|---|---|---|
| 对象关系映射 | ORM | Java 对象 ↔ 数据库表的对应 | ⬜ |
| Mapper 扫描 | `@Mapper` | 标了它，MyBatis 才会给这个接口生成实现 | ✅ |
| 基础增删改查 | `BaseMapper` | MyBatis-Plus 自带 CRUD 方法的父接口 | ✅ |
| 表名映射 | `@TableName` | 告诉它这个类对应哪张表 | ✅ |
| 列映射 | `@TableField` | 字段名和列名对不上时手工指定 | ✅ |
| 主键 | `@TableId` | 指定主键字段和生成策略 | ✅ |
| 雪花算法 | Snowflake ID | 分布式下生成不重复的 64 位 ID | ⬜ |
| 逻辑删除 | `@TableLogic` | 不真删，把 `deleted` 字段改成记录 ID | ⬜ |
| 分页 | Page / `IPage` | 只查第 N 页、每页 M 条 | ⬜ |
| 驼峰映射 | camel case → snake case | `memberNo` 自动对应 `member_no` | ✅ |

## 待补课优先级（我的判断）

1. **Maven + pom.xml**：每天都在用，不懂就看不懂报错。先补这个。
2. **Spring 的 IoC / Bean / 自动配置**：`@Autowired`、`@Service` 为什么能生效，全绕不开它。
3. **MyBatis-Plus 的 BaseMapper / 分页 / 逻辑删除**：写 CRUD 全程都在用。
4. **JSON + HTTP 状态码**：调接口、看返回、排查问题都要。
5. **Nacos / Feign / Gateway**：微服务为什么这么拆，本项目架构的核心。
6. **Docker**：起 Redis/Nacos 用得到，不懂先照抄命令也能跳过。
