## 1. Java 语言本身

| 概念 | 英文 | 一句话 | 状态 |
|---|---|---|---|
| 注解 | Annotation | `@` 开头的东西，本身不执行逻辑，是给编译器/框架看的标记 | ✅ |
| 接口 | interface | 只声明方法、没有方法体；要靠实现类补上 | ✅ |
| 实现 | implements | 一个类答应「照着接口的声明把方法写出来」 | ✅ |
| 继承 | extends | 子类直接获得父类的字段和方法 | ✅ |
| 包 | package | Java 的目录分组，包名必须和目录结构一致 | ✅ |
| 动态代理 | dynamic proxy | 运行时在内存里生成的类，接口没有方法体也能被调用 | ✅ |
| 泛型 | generics | `<T>`、`Ret<Void>`、`List<MemberInfo>` 里的尖括号部分 | ⬜ |
| 枚举 | enum | 一组固定常量（如状态码），项目里用 Integer + 常量替代 | ⬜ |
| 日期时间 | LocalDate / LocalDateTime | 新的日期/时间类型，替代老的 `java.util.Date` | ⬜ |
| 序列化 | serialization | 对象 ↔ 字节流/JSON 的转换 | ⬜ |

## 待补课优先级（我的判断）

1. **Maven + pom.xml**：每天都在用，不懂就看不懂报错。先补这个。
2. **Spring 的 IoC / Bean / 自动配置**：`@Autowired`、`@Service` 为什么能生效，全绕不开它。
3. **MyBatis-Plus 的 BaseMapper / 分页 / 逻辑删除**：写 CRUD 全程都在用。
4. **JSON + HTTP 状态码**：调接口、看返回、排查问题都要。
5. **Nacos / Feign / Gateway**：微服务为什么这么拆，本项目架构的核心。
6. **Docker**：起 Redis/Nacos 用得到，不懂先照抄命令也能跳过。

## 9. 常用命令拆解

| 命令 | 拆解 |
|---|---|
| `mvn -o -pl <模块路径> compile` | `mvn`=Maven 程序；`-o`=离线模式，只用本地仓库 `E:\study\m2repo` 不联网；`-pl`=只构建指定模块；`<模块路径>`=相对根 pom 的子模块路径；`compile`=编译阶段，产物进 `target/classes` |
| `mvn clean install -DskipTests` | `clean`=删 target；`install`=编译+打包并装进本地仓库；`-DskipTests`=跳过测试 |
| `npm run build` | `npm`=Node 包管理器；`run build`=执行 package.json 里名为 build 的脚本 |
| `git add -A` | 把所有改动加入暂存区 |
| `git commit -m "..."` | 生成一次本地提交 |
| `git push` | 把本地提交推到远程仓库 |
| `docker compose up -d` | `up`=启动容器；`-d`=后台运行（detached） |

## 11. 第 5 批新增术语（Service 层）

| 英文 / 注解 | 中文 | 作用 |
|---|---|---|
| `@Service` | 服务层组件 | 告诉 Spring「这个类是一个业务 Bean」 |
| `@Slf4j` | 日志门面 | 自动生成 `log` 对象，用 `log.info(...)` 打日志 |

| `private final` | 私有且不可变 | 注入进来的依赖，构造后不能再被改 |

| `IPage` | 分页接口 | 拿到「第几页、共多少条」的结果 |
| `Page` | 分页实现 | `new Page<>(当前页, 每页条数)` |
| `selectPage` | 分页查询 | MyBatis-Plus 自带，返回 IPage |
| `insert` | 插入 | 新增一条记录 |
| `updateById` | 按主键更新 | **只更新非 null 字段**，没传的字段保持原值 |
| `logicDeleteById` | 逻辑删除 | 把 deleted 设成记录 ID |
| `exists` | 是否存在 | 返回 true/false，用于查重 |
| `StringUtils.hasText` | 有实际内容 | 非 null 且不全空白 |
