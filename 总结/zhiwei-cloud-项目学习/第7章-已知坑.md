# 第7章 已知坑

按踩到的概率排。

## 1. 没有 spring-boot-maven-plugin

各 pom 都没声明，`mvn spring-boot:run` 报：

```text
No plugin found for prefix 'spring-boot'
```

要么用全限定坐标：

```powershell
mvn org.springframework.boot:spring-boot-maven-plugin:4.1.2:run
```

要么直接在 IDEA 里跑主类。

## 2. 目录名笔误

- `zhiwei-module-member/zhiwei-module-member-seven` 应该是 `-server`
- `zhiwei-module-booking/zhiwei-module-booking-sever` 应该是 `-server`

改名会影响根 pom 的 `<module>` 和 IDE 配置，**动之前先问负责人**。

## 3. dev 配置里密码是明文

`application-dev.yml` 写死了 PolarDB 密码，赶工阶段可以，但推到公共仓库前要意识到这是敏感信息。

## 4. Nacos 缺配置只 WARN

首次启动不用先去 Nacos 建配置文件，但业务参数会缺失，后面要补：

- `zhiwei-gateway-dev.yaml`
- `zhiwei-system-server-dev.yaml`
- `zhiwei-infra-server-dev.yaml`

## 5. docker-compose 不含 MySQL

只起 Redis + Nacos，业务库用外部 PolarDB。别去找 MySQL 容器。

## 6. .flattened-pom.xml

`flatten-maven-plugin` 的构建产物，`mvn` 跑过就在模块根目录出现。`.gitignore` 已忽略，**不要提交**。

## 7. .mvn 目录

Maven Archetype 生成模块时的副产物，`maven.config` / `jvm.config` 都是空文件，对构建无影响。

## 8. 依赖下载慢

仓库配了阿里云镜像（`~/.m2/settings.xml`），首次 `mvn clean install` 仍要下几百 MB，耐心等。

## 9. PolarDB 白名单

连不上数据库先查 IP 白名单，出口 IP 变了要加白。报错 `Connection timed out` 或 `Access denied`。

## 10. IDEA 的 SDK 要指到 JDK27

本机已只留 `E:\JDK27`。如果 IDEA 提示 SDK 无效，去 Project Structure 选 27。
