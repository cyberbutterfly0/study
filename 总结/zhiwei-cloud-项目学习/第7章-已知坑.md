# 第7章 已知坑

按踩到的概率排。

## 1. 没有 spring-boot-maven-plugin

各 pom 都没声明，`mvn spring-boot:run` 报：

```text
No plugin found for prefix 'spring-boot'
```

要么用全限定坐标：

```powershell
mvn org.springframework.boot:spring-boot-maven-plugin:4.1.2:run
```

要么直接在 IDEA 里跑主类。

## 2. 目录名笔误

- `zhiwei-module-member/zhiwei-module-member-seven` 应该是 `-server`
- `zhiwei-module-booking/zhiwei-module-booking-sever` 应该是 `-server`

改名会影响根 pom 的 `<module>` 和 IDE 配置，**动之前先问负责人**。

## 3. dev 配置里密码是明文

`application-dev.yml` 写死了 PolarDB 密码，赶工阶段可以，但推到公共仓库前要意识到这是敏感信息。

## 4. Nacos 缺配置只 WARN

首次启动不用先去 Nacos 建配置文件，但业务参数会缺失，后面要补：

- `zhiwei-gateway-dev.yaml`
- `zhiwei-system-server-dev.yaml`
- `zhiwei-infra-server-dev.yaml`

## 5. docker-compose 不含 MySQL

只起 Redis + Nacos，业务库用外部 PolarDB。别去找 MySQL 容器。

## 6. .flattened-pom.xml

`flatten-maven-plugin` 的构建产物，`mvn` 跑过就在模块根目录出现。`.gitignore` 已忽略，**不要提交**。

## 7. .mvn 目录

Maven Archetype 生成模块时的副产物，`maven.config` / `jvm.config` 都是空文件，对构建无影响。

## 8. 依赖下载慢

仓库配了阿里云镜像（`~/.m2/settings.xml`），首次 `mvn clean install` 仍要下几百 MB，耐心等。

## 9. PolarDB 白名单

连不上数据库先查 IP 白名单，出口 IP 变了要加白。报错 `Connection timed out` 或 `Access denied`。

## 10. IDEA 的 SDK 要指到 JDK27

本机已只留 `E:\JDK27`。如果 IDEA 提示 SDK 无效，去 Project Structure 选 27。

## 11. JDK 解压后的文件完整性标签是 Low（本次排查最耗时的一个）

症状：`mvn` 写本地仓库报 `AccessDeniedException`、Tomcat 报 `Unable to create tempDir`、`javac` 报「写入 xxx 时出错」、IDEA 报 `configuration.crc` AccessDenied——但目录 ACL 全正常、PowerShell 手动建文件没问题，只有 java 进程不行。

查：`icacls "E:\JDK27\bin\java.exe"`，出现 `Mandatory Label\Low Mandatory Level:(I)(NW)` 即中招。

修：

```powershell
icacls 'E:\JDK27' /setintegritylevel '(OI)(CI)M' /T
```

原理：Windows UIPI 机制，Low 完整性进程不能往 Medium（默认）目录写。JDK 从下载/解压工具继承了 Low 标签。别先去查 ACL、杀软、Defender、组策略，先查这一行。

## 12. IDEA 的 .idea/modules.xml 损坏导致 ClassNotFoundException

症状：命令行 `mvn clean install` 成功，IDEA 里运行报 `ClassNotFoundException`，或启动时缺某个依赖类。

查：`.idea\modules.xml` 里登记了几个模块、引用的 `.iml` 是否存在——正常应与项目模块数一致。

修：Maven 面板 🔄「重新加载所有 Maven 项目」；不行就关 IDEA → 备份删 `modules.xml` → 重开按提示从 pom 导入。

## 13. target/classes 只有 resources 没有 .class

构建报"成功"但 `target\classes` 里只有 `application-*.yml`、`logback-spring.xml`，没有编译出的 class → IDEA 运行时必然 ClassNotFound。

查：

```powershell
Test-Path 'zhiwei-module-system\zhiwei-module-system-server\target\classes\cloud\zhiwei\system\SystemServerApplication.class'
```

修：回项目根重跑 `mvn clean install -DskipTests`，必须看到 `Compiling N source files` 和 `BUILD SUCCESS`。
