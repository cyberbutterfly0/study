# 第3章 数据库连接

## 一、连接信息

| 项 | 值 |
|---|---|
| 类型 | 阿里云 PolarDB（MySQL 8.0 兼容） |
| 主机 | `ydmap-ops.mysql.polardb.rds.aliyuncs.com` |
| 端口 | `3306` |
| 数据库 | `test_ming_study`（开发统一库） |
| 用户名 | `ydmap_dev` |
| 密码 | 见 `zhiwei-module-*-server/src/main/resources/application-dev.yml`（不写进这份公开笔记） |
| 连接参数 | `useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true` |

system / infra / gateway 三条服务用的是同一套，写在各自的 `application-dev.yml` 里。

## 二、用 IDEA 连

右侧 **Database** 面板 → `+` → Data Source → MySQL：

- Host：`ydmap-ops.mysql.polardb.rds.aliyuncs.com`
- Port：`3306`
- Database：`test_ming_study`
- User：`ydmap_dev`
- Password：去 `application-dev.yml` 里复制
- 点 **Test Connection**

连不上先查**白名单**：PolarDB 有 IP 白名单，你家或公司出口 IP 变了就连不上，报 `Connection timed out` 或 `Access denied`，找负责人加 IP。

## 三、代码里怎么配的

`application-dev.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://ydmap-ops.mysql.polardb.rds.aliyuncs.com:3306/test_ming_study?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: ydmap_dev
    password: <去文件里看>
    driver-class-name: com.mysql.cj.jdbc.Driver
```

JDBC URL 参数逐个解释：

| 参数 | 含义 |
|---|---|
| `useSSL=false` | 内网不加密，省握手开销（生产用 true） |
| `serverTimezone=Asia/Shanghai` | 东八区，不然时间字段差 8 小时 |
| `allowPublicKeyRetrieval=true` | MySQL 8 的 caching_sha2_password 认证要取公钥 |

## 四、三个环境的差异

| 环境 | 库名 | 地址来源 | 密码来源 |
|---|---|---|---|
| dev | `test_ming_study` | 硬编码 PolarDB 域名 | 明文写在文件里 |
| test | `zhiwei_test` | `${DB_HOST:127.0.0.1}` 环境变量 | `${DB_PASS:zhiwei_test}` 带默认值 |
| prod | `zhiwei` | `${DB_HOST:127.0.0.1}` 无默认值 | `${DB_PASS}` 无默认值，没设就启动失败 |

这是刻意设计的：**生产环境宁可启动失败，也不能用错配置连错库**。

## 五、Nacos 自己的库

Nacos 也用 MySQL 存配置：

- `docker-compose.yml` 里 `MYSQL_SERVICE_HOST` 指向 `ydmap-ops.mysql.polardb.rds.aliyuncs.com`
- `MYSQL_SERVICE_DB_NAME=nacos_ming`，用户 `ydmap_dev`
- 建表脚本在仓库 `sql/nacos-mysql-schema.sql`（来自 Nacos 2.4.3 官方，172 行）
- **坑**：脚本头注释写的是 `USE test_ming_study;`，但 compose 实际用的库名是 `nacos_ming`，执行前按实际库改
