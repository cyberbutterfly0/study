## 这次补进坑里的关键事实

- 本地仓库路径不是默认的 `~/.m2/repository`，是 `E:\study\m2repo`（`settings.xml` 的 `localRepository`）。
- 全量 `mvn clean install -DskipTests` 成功后，`E:\study\m2repo\cloud\zhiwei` 下有 33 个构件目录。
- 修复验证：`mvn -pl zhiwei-module-infra/zhiwei-module-infra-server spring-boot:run` → 48082 监听成功 → `GET /api/infra/health` 返回 `{"code":0,"data":"infra-server is running"}`。
- 判断口诀：`mvn -pl <模块>` 报「程序包 `cloud.zhiwei.xxx` 不存在」时，先全量 install，别在代码里找。
