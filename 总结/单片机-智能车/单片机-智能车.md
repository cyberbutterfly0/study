# 单片机-智能车（STM32 与 MSPM0 双平台）

- 状态: 进行中
- 最后更新: 2026-10-18
- 待解决: 0
- 主题一句话: 智能车主控的软件部分——外设配置、传感器采集、控制算法、显示交互、通信，STM32 和 MSPM0 两套平台并行学。

## 硬件与工具环境

| | STM32 侧 | MSPM0 侧 |
|---|---|---|
| 主控 | STM32F103（Cortex-M3，72 MHz） | TI MSPM0（Cortex-M0+） |
| 图形配置工具 | STM32CubeMX2 1.1.1 | SysConfig |
| 底层库 | HAL（另有标准库 / LL） | DriverLib（MSPM0 SDK） |
| 开发环境 | VS Code + CubeMX2 | CCS 或 Keil（或 VS Code + TI 插件） |
| 查文档 | CubeMX2 内建 Sidekick、RM0008 | MSPM0 SDK 文档、器件数据手册 |

**器材情况**（2026-10-18 用户说明）：两块板子都是**社团提供的器材，不能外带**，只有社团活动时间能上板。所以练习分两级——

- **桌面练习**（随时可做，占多数）：默写配置步骤、手算定时时间、读代码推现象、写预期的串口输出。
- **上板任务**：攒进每章的「社团时间清单」，一次去社团做 3–4 个能在半小时内验证完的小实验，回来贴结果我评审。

**学法是"原理讲一遍、两侧各看一遍落地"**：每节讲完共通的硬件机制，再分别看 STM32 怎么配、MSPM0 怎么配，差异记进 [平台对照](./平台对照.md)。芯片无关的部分（传感器时序、PID、通信协议）只学一遍。

- **学习侧重**（用户要求）：原理 70%、编程 20%、工具操作 10%，每章另有一节讲怎么让 AI 干活并验证它的输出。规则在 `.dsh\skills\stm32-tutor\SKILL.md` 和 `.dsh\skills\stm32-tutor\references\ai-collab.md`。

## 目标

能独立写出/调试一辆智能车的软件：从建工程、配时钟和 GPIO 开始，到读光电和 MPU6050、算速度方向、用 PID 闭环驱动电机、在屏幕上显示状态、跟摄像头模块通信。

## 学习方式

这个主题**不用三级提示**（那是 study-tutor 的规矩）。这里是系统学，一轮一小节：

1. **讲**——把这一小节讲透（硬件上发生了什么、寄存器/库函数在做什么、常见误解）。
2. **考**——2–4 道选择题，当场判，逐个解释错的选项为什么错。答错的进 [错题本](./错题本.md)。题目下面配三列术语表（术语 / 含义 / 通俗解释）；全部术语汇总在 [术语表](./术语表.md)，`Ctrl+F` 能搜，问到术语或概念就直接记进去，不进错题本。
3. **练**——默认是桌面练习（推演/手算/改代码，不用板子）；需要上板的攒进本章「社团时间清单」，去社团时一次做完一批。都有验收标准，我自己做，然后贴结果评审。

每章学完补该章的「易错点」和「小结」。
