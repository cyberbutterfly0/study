# 平台对照：STM32F103 ↔ TI MSPM0

同一个概念在两套平台上的叫法、配置位置和函数名。左列是通用概念，右边两列是两侧落地方式。

> 规则：这张表只写**确认过**的内容。没查证的格子写「待补」，不凭印象填。学到哪个外设再补哪一块。

## 工具链与工程

| 通用概念 | STM32（CubeMX + HAL） | MSPM0（SysConfig + DriverLib） |
|---|---|---|
| 图形配置工具 | STM32CubeMX2（1.1.1） | SysConfig（TI） |
| 配置文件 | `.ioc` → 生成初始化 C 代码 | `.syscfg` → 生成 `ti_msp_dl_config.c/h` |
| 头文件总入口 | `stm32f1xx_hal.h` | `ti_msp_dl_config.h` + `dl_*.h` |
| 启动初始化 | `HAL_Init()` + `SystemClock_Config()` | `SYSCFG_DL_init()` |
| 主循环 | 用户 `main.c` 的 `while(1)` | 用户 `main.c` 的 `while(1)` |

**关键差别**：STM32 的 CubeMX 生成的代码和用户代码混在 `Core/Src` 里（用户代码写在 `USER CODE` 标记之间）；MSPM0 SDK 的工程一般是 SysConfig 生成配置 + 用户自己写 `main.c` 和中断文件，边界更清楚。

## 时钟

| 通用概念 | STM32F103 | MSPM0 |
|---|---|---|
| 时钟树在哪配 | CubeMX 的 Clock Configuration 页，对应 RCC 外设 | SysConfig 的 Clock 模块 |
| 外设时钟使能 | 必须手动开：`__HAL_RCC_GPIOA_CLK_ENABLE()` | 由 SysConfig 生成，在 `SYSCFG_DL_init()` 里统一开，用户不手写 |
| 系统频率 | `SystemCoreClock`（默认 72 MHz） | 由 SysConfig 决定（M0+ 一般几十 MHz，具体看型号和配置） |
| 定时器计数时钟 | APB1/APB2 预分频 ≠1 时 = PCLK ×2；=1 时 = PCLK（RM0008 RCC 章） | 待补（TIMA/TIMG 的时钟源在 SysConfig 里选，是否有类似的翻倍规则未查证） |

**学习要点**：STM32 上"忘了开外设时钟 → 外设完全不工作"是经典坑，MSPM0 由工具代劳，所以这个坑在 M0 上很少遇到——但原理要懂，否则换回 STM32 或改配置时会懵。

## GPIO

| 通用概念 | STM32F103 (HAL) | MSPM0 (DriverLib) |
|---|---|---|
| 写引脚 | `HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET)` | `DL_GPIO_setPins(GPIOA, PIN_5_PIN)` |
| 清零 | 同一个函数传 `GPIO_PIN_RESET` | `DL_GPIO_clearPins(GPIOA, PIN_5_PIN)` |
| 翻转 | `HAL_GPIO_TogglePin(port, pin)` | `DL_GPIO_togglePins(port, mask)` |
| 读引脚 | `HAL_GPIO_ReadPin(port, pin)` | `DL_GPIO_readPins(port, mask)` |
| 模式配置 | CubeMX 里选 Input/Output/Alternate/Analog + Pull-up/down | SysConfig 的 GPIO 模块里选方向、上下拉、复用功能 |
| 端口实例 | GPIOA/GPIOB/GPIOC（F103C8T6 有 A/B/C） | GPIOA/GPIOB（端口数随型号，具体看数据手册） |

**关键差别**：HAL 是"一次一个引脚"的函数风格，DriverLib 是"一次一组引脚（掩码）"的风格。

## 串口 UART

| 通用概念 | STM32F103 (HAL) | MSPM0 (DriverLib) |
|---|---|---|
| 发一段数据 | `HAL_UART_Transmit(&huart1, buf, len, timeout)` | `DL_UART_Main_transmitDataBlocking(UART_0_INST, c)` 逐字节（待补：是否有批量接口） |
| 收一个字节 | `HAL_UART_Receive(...)` | `DL_UART_Main_receiveData(UART_0_INST)` |
| 中断接收 | CubeMX 开 UART 全局中断 + `HAL_UART_Receive_IT` | 配置 UART 中断 + 写 `UART_0_INST_IRQHandler` |
| `printf` 重定向 | 自己写 `fputc` 指向 UART | 同样要自己写 `fputc`/`putchar`（待补 TI 官方写法） |

## 待补的模块

学到再填，不要提前编：

- **中断**：NVIC 使能、优先级位宽（M0+ 只有 2 位优先级，比 M3 窄）、中断向量命名
- **定时器 / PWM**：TIMG/TIMA 与 TIM1/TIM2 的对应、计数模式、PWM 启动函数
- **ADC**：ADC12 与 STM32 ADC 的通道映射、单次/连续/DMA 采样
- **DMA**：通道分配、触发源、与 ADC/UART 的配合
- **I2C**：MPU6050 读写寄存器、地址写法（HAL 要左移）

## 学习顺序

两边并行时按这个节奏：

1. 先在 F103 上把一个外设跑通——手边有板子、反馈快、资料多
2. 立刻在 MSPM0 上做同一件事，只关注"配置在哪、函数叫什么"
3. 差异记进这张表，规律相同的部分不用重复记

芯片无关的部分（传感器时序、PID、控制逻辑、通信协议格式）只学一遍。
