# 术语表（单片机-智能车）

> 用法：电脑上按 `Ctrl+F` 直接搜术语名。阅读版（`总结/_阅读版/`）里同样能搜。
> 三列含义：**术语 ｜ 含义（准确定义，能对上手册的说法） ｜ 通俗解释（大白话或类比）**。
> 规则：我问到的术语和概念，答案直接记进这张表，不进错题本、不单独建文档。

## 时钟与电源

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| HSE | High-Speed External，外部高速时钟源，接在 OSC_IN/OSC_OUT 引脚上的晶振 | 板子上焊的那颗晶振，一般 8 MHz |
| HSI | High-Speed Internal，芯片内部 RC 振荡器，出厂校准到 8 MHz | 芯片自带的小闹钟，不用外接元件，但不如晶振准 |
| LSI | Low-Speed Internal，内部低速时钟，约 40 kHz，主要给看门狗和 RTC | 慢速备用表，专门管"看门狗"这种慢活 |
| PLL | Phase-Locked Loop，锁相环，把输入时钟按倍频系数抬高 | 倍速器，8 MHz 进去、72 MHz 出来 |
| SYSCLK | 系统主时钟，CPU 实际运行的频率 | CPU 真正用的那个节拍 |
| HCLK | AHB 总线时钟，= SYSCLK / AHB 分频 | 主节拍分给高速总线的频率 |
| PCLK1 / PCLK2 | APB1 / APB2 外设总线时钟，= HCLK / 对应 APB 分频 | 外设总线的节拍，APB1 最高 36 MHz、APB2 最高 72 MHz |
| AHB / APB | 两条片上总线：AHB 接高速部件，APB 接外设 | 芯片里的两级公路，快车走 AHB、外设走 APB |
| RCC | Reset and Clock Control，管理复位与时钟的外设 | 总电闸加时钟分配器，"开外设时钟"就是写它 |
| 预分频（Prescaler） | 把输入时钟按整数比例降频的分频器 | 把快节拍切成慢节拍 |
| 门控（Clock Gating） | 用使能位切断某个外设的时钟，省电 | 给每个外设一个独立开关，不用就关掉 |

## GPIO 与中断

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| GPIO | General Purpose Input/Output，通用输入输出端口 | 芯片上的万能引脚，可当开关读、也可当灯泡点 |
| 推挽输出 | 输出级上下管都工作，能主动拉高也能拉低 | 有力气把线"顶"到高、也"拽"到低 |
| 开漏输出 | 只有下管，只能拉低，拉高要靠外部上拉电阻 | 只会往下拽，往上得靠外面拉 |
| 上拉 / 下拉 | 用电阻把引脚空闲状态固定到高 / 低电平 | 没人说话时让它默认喊"高"或"低" |
| 复用（Alternate Function） | 把引脚的控制权交给某个外设（如 USART1_TX） | 同一根引脚改插到别的设备上 |
| 中断 | 事件发生时打断 CPU 当前流程，先处理它 | 有人拍肩膀，先放下手上的活 |
| 中断服务函数（ISR） | 中断触发后由硬件跳转执行的那个函数 | 被拍肩膀后专门去干的活 |
| NVIC | Nested Vectored Interrupt Controller，Cortex-M 的中断控制器 | 管所有中断的调度员 |
| 抢占优先级 / 子优先级 | 决定谁能打断谁、同级谁先执行 | 排队的规矩：谁插队、谁先办 |

## 定时器与 PWM

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| 计数时钟 | 定时器计数器每加一所用的频率 | 秒表走一格的快慢 |
| 定时器时钟 ×2 规则 | APB 预分频系数 ≠1 时，定时器计数时钟 = PCLK ×2；分频为 1 时 = PCLK | 总线被降速了，定时器单独开小灶，节拍不跟着降 |
| 预分频（PSC） | 定时器输入时钟的分频寄存器 | 把节拍放慢的旋钮 |
| 自动重装载（ARR） | 计到该值后归零并产生更新事件的寄存器 | 数到几就从头再数 |
| 更新事件 | 计数器溢出/重装时产生的事件 | "这一轮数完了"的信号 |
| PWM | Pulse Width Modulation，脉冲宽度调制 | 用开关得很快的方式模拟中间电压 |
| 占空比 | 一个周期里高电平占的比例 | 一个周期里"开"的时间占几成 |
| 输入捕获 | 记录引脚跳变发生时的计数值 | 掐表量事件发生的时刻 |
| 输出比较 | 计数到设定值时改变输出引脚 | 数到某个点就动作 |

## 串口与通信

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| UART | Universal Asynchronous Receiver/Transmitter，通用异步收发器 | 最常用的串口，两根线收发 |
| 波特率 | 每秒传输的位数（bit/s） | 说话的语速，两边必须一样 |
| 异步 | 没有共享时钟线，靠双方约定波特率对齐 | 没节拍器，各凭手表对时间 |
| TX / RX | 发送引脚 / 接收引脚 | 一根嘴、一根耳朵，要交叉接 |
| I2C | 两线制同步总线（SCL 时钟、SDA 数据），器件带地址 | 一根时钟线一根数据线，按门牌号找人 |
| 上拉电阻 | I2C 开漏总线必须外接，否则线拉不到高电平 | 总线没人拽的时候得有人把它提起来 |
| SPI | 四线制同步总线（SCK/MOSI/MISO/NSS） | 时钟、发、收、选中，四根线各管一摊 |

## ADC 与 DMA

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| ADC | Analog-to-Digital Converter，模数转换器 | 把电压这种连续量变成数字 |
| 采样时间 | 采样保持电容充电所需的时间 | 舀一勺水要等它盛满 |
| 分辨率 | ADC 输出位数，F103 是 12 位，范围 0–4095 | 尺子有多细 |
| 参考电压（VREF+） | 换算公式里的满量程电压 | 尺子的总长度，一般 3.3 V |
| DMA | Direct Memory Access，直接内存访问，数据搬运不经过 CPU | 雇个搬运工，CPU 不用自己搬 |
| 传输完成中断 | DMA 把数据搬完时发出的通知 | 搬运工说"搬完了" |

## 工具与库

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| CubeMX / CubeMX2 | ST 的图形化配置工具，按图形界面生成初始化代码 | 点鼠标配引脚和时钟，自动写代码 |
| HAL | Hardware Abstraction Layer，ST 的硬件抽象库 | 官方写好的封装函数，`HAL_` 开头 |
| LL | Low Layer，比 HAL 更贴近寄存器的轻量库 | 半封装，少绕几层 |
| SysConfig | TI 的图形化配置工具，MSPM0 上对应 CubeMX 的角色 | TI 版的"点鼠标配置" |
| DriverLib | TI MSPM0 的外设驱动库，函数以 `DL_` 开头 | TI 版的 HAL |
| `.ioc` | CubeMX 工程配置文件 | 保存引脚/时钟配置的工程文件 |
| `.syscfg` | SysConfig 配置文件 | MSPM0 那边的同类文件 |
| CMSIS | Cortex-M 内核的标准软件接口层 | 内核层面的公共插座，各家芯片都用 |

## 传感器与控制算法

| 术语 | 含义 | 通俗解释 |
|---|---|---|
| 光电传感器 | 通过遮挡光路产生电平变化的传感器 | 挡一下光就报一次"有人经过" |
| 编码器 | 把转动变成脉冲/计数的传感器 | 数转了多少格 |
| MPU6050 | 六轴传感器（三轴加速度 + 三轴陀螺仪），I2C 接口 | 同时测"往哪歪"和"转得多快" |
| 互补滤波 | 用加速度计修正陀螺仪的低频漂移，短时信陀螺仪 | 一个管短跑、一个管长跑，按频率分工 |
| 卡尔曼滤波 | 结合系统模型与测量的最优估计方法 | 用"预测 + 实测"互相纠偏 |
| PID | 比例（P）-积分（I）-微分（D）控制器 | 按"差多少、差多久、差得多快"三路合力 |
| 增量式 PID | 输出每次的增量，累加得到实际控制量 | 每次只调一点点 |
| 位置式 PID | 直接输出控制量的绝对值 | 每次直接给"该到哪" |
| 积分饱和 | 误差长期存在导致积分项累积过大，输出超出范围 | 越攒越使劲，最后刹不住 |
