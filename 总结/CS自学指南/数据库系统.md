### 1.1 CMU 15-445: Database Systems

- 学校：CMU
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：C++、数据结构与算法、CMU 15-213（CS:APP）
- 语言：C++
- 定位：CMU 数据库入门课，Andy Pavlo 讲授；Faculty 与 CMU Database Group 把 Autograder、Discord、Lectures、Notes、Homework 全部开源，体验接近 CMU 本校学生。
- 作业/项目：围绕教学用关系型数据库 bustub，四个 Project 依次实现 Buffer Pool Manager、B Plus Tree、Query Executors & Query Optimizer、Concurrency Control。可用 shell.cpp 编译出 bustub-shell 实时验证自己的实现，正反馈很足；bustub 本身也是学习程序构建、代码规范、单元测试的优秀 C++ 项目。
- 自学建议：必做，且建议四个 Project 全部做完。注意版本差异：Fall 2019 的 Project #2 是哈希索引、#4 是日志与恢复；Fall 2021 的 #1 是缓存池、#2 哈希索引、#4 并发控制；Fall 2022 把哈希索引换成 B+ 树；Spring 2023 与 Fall 2022 大体相同，但 Project #0 换成 Copy-On-Write Trie，并加了注册大小写函数的 Task。2020 年以前的 bustub 版本已停止维护，Fall 2019 的 Logging & Recovery Project 已经 broken，只建议看代码和 handout。遇到卡点可查非官方 Discord 的历史记录，结束后推荐读论文 Architecture Of a Database System。
- 链接：未标（页面未给课程官网；课程资料与 Discord 均开源）

### 1.2 CMU 15-799: Special Topics in Database Systems

- 学校：CMU
- 难度：★★★☆☆
- 学时：约 80 小时
- 先修：CMU 15-445
- 语言：C++
- 定位：数据库前沿专题，至今只开过两次——fall2013 讨论 Streaming、Graph DB、NVM 等，spring2022 主要讨论 Self-Driving DBMS，均配相关论文。
- 作业/项目：spring2022 两个任务：一是基于 PostgreSQL 做手动性能调优；二是基于 NoisePage Pilot 改进 Self-Driving DBMS，特性不限。授课偏讲座形式，编程任务较少。
- 自学建议：不是入门课，要先有 15-445 基础。对一般同学是开拓视野，对专精数据库的同学帮助更大；按论文清单读比追作业更划算。

### 1.3 Caltech CS 122: Database System Implementation

- 学校：Caltech
- 难度：★★★★★
- 学时：约 150 小时
- 先修：无
- 语言：Java
- 定位：与不提供 SQL 层功能的 CMU 15-445 互补，Lab 侧重 SQL 层实现：SQL 解析、Translate、Join 实现、统计信息与代价估计、子查询、Agg、Group By，另外还有 B+ 树与 WAL 实验。
- 作业/项目：7 个 Assignment + 2 个 Challenge，在 NanoDB 上做。Assignment1 给 NanoDB 加 delete/update 支持、给 Buffer Pool Manager 补 pin/unpin、提升 insert 性能且不让数据库文件过度膨胀；Assignment2 实现简单计划生成器（Parser 后的 SQL 转执行计划）、用 nested-loop join 实现支持 inner/outer join 的计划节点并补单元测试；Assignment3 收集表统计信息、计算各计划节点成本、计算谓词选择性、按谓词更新计划节点输出的元组统计信息。强度接近从零写一个查询优化器。
- 自学建议：适合学完 CMU 15-445 之后、对查询优化有兴趣再上。工具链用 IDEA 打开工程、Maven 构建，注意日志相关配置这个坑。
- 链接：http://courses.cms.caltech.edu/cs122/

### 1.4 UCB CS186: Introduction to Database System

- 学校：UC Berkeley
- 难度：★★★★★
- 学时：约 150 小时
- 先修：CS61A、CS61B、CS61C
- 语言：Java
- 定位：从"SQL 怎么写"一路讲到"SQL 如何被拆解、优化成磁盘查询指令"，覆盖高并发、故障恢复、非关系型数据库，最终动手用 Java 实现一个支持 SQL 并发查询、B+ 树索引与故障恢复的关系型数据库。
- 作业/项目：6 个 Project，实现数据库内核；同时训练写 SQL 与 NoSQL 查询的能力，对做全栈项目直接有用。
- 自学建议：先修链条最长（61A/B/C），没有 Java 与系统基础会比较吃力。适合作为数据库方向的主干课，与 15-445 二选一或先后互补；有 B 站课程视频可跟。
- 链接：https://cs186berkeley.net/

### 1.5 Stanford CS 346: Database System Implementation

- 学校：Stanford
- 难度：★★★★★
- 学时：约 150 小时
- 先修：无
- 语言：C++
- 定位：以 RedBase 项目为主线实现一个简易数据库系统，项目高度结构化，代码量不大、便于按需扩展，也可顺带练 C++。
- 作业/项目：4 个 Lab + 1 个 Extension。记录管理组件；B+ 树索引组件；系统管理组件（DDL 语句、命令行工具、数据加载命令、元数据管理）；查询语言组件（实现 RQL，支持 select/insert/delete/update）；扩展组件可选 Blob 类型、网络模块、连接算法、CBO 优化器、OLAP、事务等。
- 自学建议：定位是学完 CMU 15-445 之后的补充课，用来补齐 15-445 没覆盖的组件；因为代码量少，适合作为自己加功能的练手底座，不适合当第一门数据库课。
- 链接：https://web.stanford.edu/class/cs346/2015/
