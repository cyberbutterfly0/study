# CS 自学指南（csdiy.wiki 整理版）

> 来源：https://csdiy.wiki/ （CS 自学指南，北大 PKUFlyingPig 维护的开源手册）。本目录按它的分类体系逐类整理：每门课一份精简学习卡，字段固定为学校 / 难度 / 学时 / 先修 / 语言 / 定位 / 作业项目 / 自学建议 / 链接。
>
> 抓不到的数据一律写「未标」，没有凭印象补。

## 怎么用这套笔记

1. **先定方向**：看下面的分类表，挑和自己目标相关的板块（找工作刷题、读研做科研、还是把工程底子补牢）。
2. **读课程卡**：每门课先看「定位」判断要不要学，再看「先修」确认自己接不接得住，最后看「作业项目」判断值不值得花时间。
3. **别只看不写**：csdiy 所有课的精髓都在 lab/作业。课程卡里的「作业项目」就是判断一门课能不能真正练到手的依据。
4. **在 app 里配套练**：编程题去「CS自学指南 → 编程练习」刷题页写代码，写完点「AI 判定」对照判定标准批改；草稿自动存本机，手机上写完点「同步到电脑」，电脑端 `node tools/sync-in.mjs <备份文件>` 就能把草稿和判定结果收进来。

## 建议的自学顺序

按「先能写代码 → 再懂机器 → 再做方向」的顺序走，每个阶段挑 1–2 门学透，别同时开四门：

1. **编程入门**：编程入门里挑一门（C 或 Python）+ 数据结构与算法（6.006 或 CS61B）。
2. **数学**：数学基础里的 18.06 线代 + 概率论，边学边补。
3. **系统**：计算机系统基础（CSAPP）→ 操作系统（6.1810 或 CS162）→ 计算机网络 → 数据库系统。
4. **方向**：想找工作补软件工程 + 并行与分布式；想读研做 AI 走 机器学习 → 深度学习 → 机器学习系统；想做图形走 计算机图形学。

## 说明

- 每个分类文件里，课程编号 `N.M` 只是章节内的顺序号，不代表学习先后。
- 难度按 csdiy 页面的星数转换：★ 实心表示难度，空心补齐；页面标 6 星以上的按原文星数写并加注。
- 学时按页面原文转写；页面写「因人而异」的写「未标（原文写因人而异）」。
- 「链接」只写页面里真实出现的 URL；页面只给链接文字、抓不到 href 的写「未标」，不按印象补。
