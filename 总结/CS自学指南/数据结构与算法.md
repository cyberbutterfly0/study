### 1.1 MIT 6.006: Introduction to Algorithms

- 学校：MIT
- 难度：★★★★★
- 学时：约 100 小时以上（页面写 100h+）
- 先修：计算机导论（CS50/CS61A 或同等水平）
- 语言：Python
- 定位：MIT EECS 的算法入门课，授课老师之一是 Erik Demaine；相比 CS106B/X 更侧重算法的详细讲解，也覆盖 AVL 树等经典数据结构，比 CS106B 讲得更细。
- 作业/项目：页面只给出 Fall 2011 的作业页（OCW Assignments）链接，未列具体作业数量与项目；教材为 CLRS。
- 自学建议：按页面说法适合在 CS106B/X 入门之后用来巩固算法；但这门课「出了名的难」，开始前要有心理准备。
- 链接：https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/

### 1.2 MIT 6.046: Design and Analysis of Algorithms

- 学校：MIT
- 难度：★★★★★
- 学时：约 100 小时以上（页面写 100h+）
- 先修：算法入门（6.006/CS61B/CS106B/CS106X 或同等水平）
- 语言：Python
- 定位：6.006 的后续课，老师仍是 Erik Demaine 与 Srini Devadas，另加 Nancy Lynch；重点从「现学现用」转为举一反三，自己设计完整算法并证明它能解决问题。
- 作业/项目：基本没有编程作业，绝大部分作业是给出要求后做算法设计加正确性证明，所以难度比 6.006 又高一截；教材为 CLRS。
- 自学建议：必须先学完 6.006。页面提到后面还有 6.854 高级算法，但对绝大多数考试和应聘来说，学完 6.046 已能覆盖 99% 的题目。
- 链接：https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/

### 1.3 Coursera: Algorithms I & II

- 学校：Princeton
- 难度：★★★☆☆
- 学时：约 60 小时
- 先修：CS61A
- 语言：Java
- 定位：Coursera 上评分最高的算法课，Robert Sedgewick 讲授 Algorithms I & II，能把复杂算法讲得极为生动浅显，页面作者称困扰多年的 KMP 与网络流是在这门课上弄通的。
- 作业/项目：10 个 Project，都有实际问题背景、充分测试样例和自动评分（代码风格也计入评分）；课程还提供教授写的全部数据结构与算法实现，属工业级代码而非 demo。
- 自学建议：课程结构贴合「为什么这么做 / 如何实现 / 用它解决实际问题」三步，配合开源教材 algs4 与开源代码学效果最好；难度中等，适合作为第一门系统的算法课。
- 链接：https://www.coursera.org/learn/algorithms-part1

### 1.4 CS170: Efficient Algorithms and Intractable Problems

- 学校：UC Berkeley
- 难度：★★★☆☆
- 学时：约 60 小时
- 先修：CS61B、CS70
- 语言：LaTeX（页面标注，实际指作业用 LaTeX 排版）
- 定位：伯克利的算法设计课，更注重理论基础与复杂度分析；内容覆盖分治、图算法、最短路、生成树、贪心、动规、并查集、线性规划、网络流、NP 问题、随机算法、哈希算法。
- 作业/项目：13 次书面作业，推荐用 LaTeX 编写，没有编程作业；教材即课程网站上的 notes，证明浅显易懂，适合当工具书查。
- 自学建议：想练 LaTeX 可以借这门课顺手练；偏理论、代码量少，适合在 CS61B 与 CS70 之后补算法证明与复杂度分析。
- 链接：https://cs170.org/

### 1.5 CS61B: Data Structures and Algorithms

- 学校：UC Berkeley
- 难度：★★★☆☆
- 学时：约 60 小时
- 先修：CS61A
- 语言：Java
- 定位：伯克利 CS61 系列第二门课，讲数据结构与算法的设计，同时通过 Java 让学生接触上千行的工程代码，初步领会软件工程的做法。
- 作业/项目：2018 年春季版本是 14 个 Lab（自己实现课上讲的绝大部分数据结构）+ 10 个 Homework（用数据结构与算法解决实际问题）+ 3 个 Project（上千行工程代码）；autograder 已开源，用 Gradescope 课程码 MB7ZPY 可免费加入自测（SP2021 版本对公众开放）。
- 自学建议：没有 Java 基础也能上，课程从 IDEA 配置讲起，把 Java 核心语法讲得很细；作为数据结构入门的主力课最合适，想再加深算法再去 6.006/6.046。
- 链接：https://sp24.datastructur.es/
