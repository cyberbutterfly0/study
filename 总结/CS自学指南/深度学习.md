### 1.1 CMU 11-785: Introduction to Deep Learning

- 学校：CMU
- 难度：★★★★★
- 学时：120 小时
- 先修：线性代数、概率论、Python 编程、机器学习基础
- 语言：Python
- 定位：CMU 的硬核深度学习核心课，从神经网络基础讲到 CNN、RNN、Attention/Transformer、优化与泛化，适合想把理论和实践一起打牢的人；页面形容其学习体验接近「研究生强度训练」。
- 作业项目：未标（页面只写「课程网站发布，通常包含多个编程作业与课程项目」，未列具体作业；并强调作业不是套模板跑通，而要求理解模型行为、训练细节和实验设计）
- 自学建议：页面判断这门课节奏快、几乎没有「水内容」，投入产出比高但强度大。建议概率、线代、机器学习基础都扎实后再上，把它当主线课而不是补充课，按 120 小时以上留实验时间。
- 链接：https://deeplearning.cs.cmu.edu/S26/index.html

### 1.2 CS224n: Natural Language Processing

- 学校：Stanford
- 难度：★★★★☆
- 学时：80 小时
- 先修：深度学习基础 + Python
- 语言：Python
- 定位：Stanford 的 NLP 入门课，Chris Manning 领衔，覆盖词向量、RNN、LSTM、Seq2Seq、机器翻译、注意力机制、Transformer 等 NLP 核心知识点。
- 作业项目：5 个编程作业 + 1 个 Final Project。5 个作业难度循序渐进，依次是词向量、word2vec 算法、Dependency parsing、机器翻译、Transformer 的 fine-tune；大作业在 Stanford 的 SQuAD 数据集上训练 QA 模型，页面提到有学生的大作业直接发表了顶会论文。
- 自学建议：按 5 个作业的顺序做，前面的词向量/word2vec 是后面 Transformer fine-tune 的地基；大作业选 SQuAD 这类真实任务，比刷小数据集更能练到工程能力。作者的完整作业实现见 https://github.com/PKUFlyingPig/CS224n 。
- 链接：http://web.stanford.edu/class/cs224n/index.html （视频：页面只写「B 站搜索 CS224n」，未给具体链接；教材：无）

### 1.6 CS285: Deep Reinforcement Learning

- 学校：UC Berkeley
- 难度：★★★★☆
- 学时：80 小时
- 先修：CS188, CS189
- 语言：Python
- 定位：Sergey Levine 讲授的深度强化学习课，覆盖深度强化学习各方面内容，要求了解马尔可夫决策过程（MDP）等；公式较多，教授每年按最新研究进展更新内容和作业。
- 作业项目：5 个编程作业，主要是复现经典模型并做模型间对比，偶尔复现较新的模型，最后交一份报告；作业已给框架、按 hint 填空，页面评价难度不大。
- 自学建议：页面认为适合新手入门深度强化学习，但越到后面越难，先补 MDP 和机器学习基础。22Fall 的授课方式是课前看录播、课上 Q&A，所以给出的视频链接已包含全部内容，自学只看视频即可。
- 链接：http://rail.eecs.berkeley.edu/deeprlcourse/ ；视频：https://www.youtube.com/playlist?list=PL_iWQOsE6TfX7MaC6C3HcdOf1g337dlC9 （教材：无）

### 1.7 UMich EECS 498-007 / 598-005: Deep Learning for Computer Vision

- 学校：UMich
- 难度：★★★★☆
- 学时：60～80 小时
- 先修：Python基础，矩阵论(熟悉矩阵求导即可)，微积分
- 语言：Python
- 定位：UMich 的计算机视觉课，主讲 Justin Johnson（李飞飞博士毕业生、2017 版 Stanford CS231n 主讲人）。视频和作业质量极高，覆盖 CV 主流模型发展的全阶段，是很好的 CV 入门课，且不需要任何深度学习框架经验。
- 作业项目：6 个 Assignment + 1 个 Mini-Project。A1 学 PyTorch 和 Google Colab；A2 搭线性分类器和两层神经网络，在 MNIST 上训练评估；A3 卷积神经网络（CNN）；A4 物体检测全流程，跟随 handout 实现 One-Stage 和 Two-Stage Detector；A5 从 CNN 到 RNN，搭 Vanilla RNN/LSTM 和 Transformer 两种注意力模型；A6 实现 VAE 和 GAN 并跑在 MNIST 上，再做网络可视化和风格迁移。Autograder 只对校内注册学生开放，但 handout 的 .ipynb 已能确认实现正确性和预期结果。
- 自学建议：每个 Assignment 跟随 handout 搭模型，按 A1→A6 顺序做，主题递进，能亲身体会 CV 模型的发展脉络；推荐看 YouTube 上的 Lectures，讲得很清楚。教材只有推荐书目（https://www.deeplearningbook.org/ ），可参考 @Michael-Jetson 的二三十万字笔记：https://github.com/Michael-Jetson/ML_DL_CV_with_pytorch
- 链接：https://web.eecs.umich.edu/~justincj/teaching/eecs498/WI2022/ ；视频：https://www.youtube.com/playlist?list=PL5-TkQAfAZFbzxjBHtzdVCWE0Zbhomg7r

### 1.8 國立台灣大學：李宏毅机器学习

- 学校：國立台灣大學
- 难度：★★★★☆
- 学时：80 小时
- 先修：熟练掌握 Python
- 语言：Python
- 定位：李宏毅的机器学习课，挂着机器学习的牌子但内容覆盖深度学习绝大多数领域，适合先广度扫一遍、再决定深入哪个方向。
- 作业项目：正文说作业共 15 个 lab，分别是 Regression、Classification、CNN、Self-Attention、Transformer、GAN、BERT、Anomaly Detection、Explainable AI、Attack、Adaptation、RL、Compression、Life-Long Learning、Meta Learning；但课程资源栏又写 Spring2023 为 5 个 lab、Spring2025 主要关注 AI Agent 等 LLM 相关领域（两处说法不一致，按原文并列）。所有作业都提供助教示例代码，数据处理和模型搭建已写好，只需在其基础上适量修改。
- 自学建议：页面提醒 2025 版课程内容改革，更侧重 RAG、AI Agent、LLM，与 2023 版及之前差异极大，先决定学哪一套再开始；部分 colab 作业可能打不开，这时可参考李宏毅的 GitHub。想水课程大作业的话，页面也说这里是很好的资料来源。
- 链接：Spring2023 https://speech.ee.ntu.edu.tw/~hylee/ml/2023-spring.php ；Spring2025 https://speech.ee.ntu.edu.tw/~hylee/ml/2025-spring.php （教材：无）
