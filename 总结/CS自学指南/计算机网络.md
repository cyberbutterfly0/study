### 1.1 CS144: Computer Network

- 学校：Stanford
- 难度：★★★★★
- 学时：约 100 小时
- 先修：一定的计算机系统基础，CS106L
- 语言：C++
- 定位：用 C++ 循序渐进搭出整个 TCP/IP 协议栈，主讲人之一是网络领域巨擘 Nick McKeown；作者认为它更像"年轻人最好的现代 C++ 入门课"。
- 作业/项目：8 个 checkpoint。0 是 warmup（telnet、netcat、写 webget 爬虫、In-Memory Reliable Byte Stream）；1-3 实现可与工业级实现互通的 TCP；4 用 TCPMinnowSocket 替换内核 tcp_socket 并分析真实网络（RTT >= ~100ms）流量、自己做可视化；5 实现 NetworkInterface 与 ARP；6 实现 IP Router；7 用 endtoend.cc 把所有组件串起来，经中继服务器 cs144.keithw.org 实时通信。强度很大，且其中两个 lab 不必亲自写代码。
- 自学建议：只把 8 个 checkpoint 刷完会错过大部分精华，真正的价值在框架代码——TCPSender/TCPReceiver 如何拼成双向可靠字节流、TCPMinnowSocket 如何替换内核 TCP、三次握手在哪、多线程怎么处理。注意课程 GitHub 仓库每年清空、官网无官方归档，务必先 fork；2024 Winter 网站有 Wayback 备份。初学者可借助 LLM 降低读框架的门槛。
- 链接：https://cs144.github.io/

### 1.2 CS 168: Introduction to the Internet: Architecture and Protocols

- 学校：UC Berkeley
- 难度：★★★☆☆
- 学时：约 140 小时（14 周 × 10 小时/周）
- 先修：CS 61B；推荐 CS 61C；具备基础 Python 编程和 Unix 使用经验
- 语言：Python、Unix shell
- 定位：Internet 架构与协议概论，讲分层、寻址、域内与域间路由、可靠传输、拥塞控制，以及 TCP、UDP、IP、DNS、HTTP 等核心协议，并介绍以太网、无线等网络技术。
- 作业/项目：三个 Python 项目（Traceroute、路由、TCP 传输），页面评价"相对简单"；结合理论与实践，目标是让学生动手构建并调试网络协议。
- 自学建议：配套教材写得全面又简洁生动，值得细读，也可当手册查阅，建议按教材主线推进；项目难度不高，适合作为组网与协议的第一门系统课，但想练硬核编程要另找课。
- 链接：课程官网页面仅标"SP2025"，未给具体 URL；教材 https://textbook.cs168.io/

### 1.3 Computer Networking: A Top-Down Approach

- 学校：马萨诸塞大学（教材作者 Jim Kurose、Keith Ross）
- 难度：★★★☆☆
- 学时：约 40 小时
- 先修：有一定的计算机系统基础
- 语言：无（页面标"无"）
- 定位：《自顶向下方法》经典教材的配套课程，作者公开了自录网课视频、交互式在线章节测试，以及用 Wireshark 抓包分析的 lab。
- 作业/项目：以 Wireshark 抓包分析 lab 和在线章节测试为主，没有硬核编程作业；页面明确说这块短板可由 Stanford CS144 弥补。
- 自学建议：适合作为计算机网络的第一门课，40 小时即可过一遍概念与协议栈全貌；想要编程强度就接 CS144。学习路径建议先看视频＋做章节测试，再动手抓包。
- 链接：未标（页面未给课程官网）

### 1.4 USTC Computer Networking: A Top-Down Approach

- 学校：中国科学技术大学（授课教师：郑烇、杨坚）
- 难度：★★★☆☆
- 学时：约 40 小时
- 先修：操作系统（非必需）
- 语言：无（页面标"无"）
- 定位：中文互联网上较火的计算机网络课，教材用《计算机网络（自顶向下方法）》，授课偏实际而非纯理论，内容覆盖自顶向下方法的大部分内容并涵盖考试内容。
- 作业/项目：页面未标具体作业；提供课程课件下载（cn.zip），视频为郑烇老师本人在 B 站上传，2020 年至今坚持在评论区答疑。
- 自学建议：强烈建议先读教材预习再看课，否则上课容易懵；中文讲授、配套课件齐全，适合零基础或备考人群当作第一遍系统学习。
- 链接：http://staff.ustc.edu.cn/~qzheng/teaching.html
