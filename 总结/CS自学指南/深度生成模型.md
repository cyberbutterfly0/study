## 学习路线

站内路线图先立了一个判断：大语言模型只是深度生成模型的一个分支，VAE、GAN、Diffusion、Flow 这些仍在「生成」领域占重要地位，AIGC 泛指这一类技术。下面按生成模型主线与大语言模型方向分别列推荐课程。

生成模型主线：

- MIT 6.S184：IAP 小学期入门课，从微分方程视角讲 Flow Matching 与 Diffusion 的数学原理，配简单小实验，适合对底层数学感兴趣的人入门。
- MIT 6.S978: Deep Generative Models：何恺明授课，覆盖各种生成模型的基础理论与前沿论文，几次作业都有脚手架代码，难度不高但能快速建立全貌。
- Stanford CS236: Deep Generative Models：Stefano Ermon 主讲，从自回归模型与最大似然出发，系统覆盖 VAE、Normalizing Flow、GAN、EBM、Score-based Model、Diffusion；偏概率建模视角，ELBO、Change of Variables、Score Matching 都从头推导。想搞懂各种生成模型为什么这样设计，推荐拿它作主线。
- UCB CS294-158-SP24: Deep Unsupervised Learning：Pieter Abbeel 主讲，内容比 MIT 的课更全，有配套视频和 Slides；作业只给测试代码，模型架构与训练代码要自己写，硬核但适合练手。
- CMU 10423: Generative AI：相比前几门更侧重大语言模型，其余内容重合较多，作业有意思。

大语言模型方向：

- Stanford CS336: Language Modeling from Scratch：从零写 tokenizer、模型架构、训练优化器、底层算子、训练数据清洗、后训练算法；每次作业 handout 有四五十页 pdf。
- CMU 15-779：偏系统与性能优化，讲高层模型如何分解成 kernel 并在异构加速器与分布式环境高效执行。
- CMU 11-868：LLM 系统课，侧重 GPU 加速、分布式训练与推理等底层优化，作业先实现迷你 PyTorch 再做系统级优化。
- CMU 11-667 与 CMU 11-711：偏上层算法与应用，每节课列大量阅读材料，适合先摸清各子方向再深入。

其他资料：Awesome-LLM（大模型资料汇总）、LLMSys-PaperList（系统论文汇总）、MLsys-Guide（深度学习系统入门指南）。

下面 1.2 至 1.5 是「大语言模型」子目录下的四门课，1.1 与它们同属本分类。

### 1.1 MIT 6.S184: Generative AI with Stochastic Differential Equations

- 学校：MIT
- 难度：★★★★☆
- 学时：约 20 小时
- 先修：深度学习基础，微积分与线性代数过关
- 语言：Python（PyTorch）
- 定位：MIT CSAIL 在 IAP 小学期开的扩散模型入门课，从微分方程视角讲扩散模型与流匹配模型的数学基础，并让学生从零构建扩散模型。
- 作业/项目：三个实验，具体见课程网站。
- 自学建议：配套教材《An Introduction to Flow Matching and Diffusion Models》写得很好，建议细读；最后通过讲座介绍分子设计、机器人等应用。主讲为 Peter Holderrieth 与 Ezra Erives。
- 链接：https://diffusion.csail.mit.edu/

### 1.2 CMU 11-667: Large Language Models: Methods and Applications

- 学校：Carnegie Mellon University
- 难度：★★★★☆
- 学时：约 100 小时以上
- 先修：机器学习基础（约 10-301/10-601）、NLP 基础（约 11-411/11-611），熟练 Python 与 PyTorch
- 语言：Python
- 定位：研究生 LLM 方法与应用的全面课：网络架构、训练、推理、评估，解释性、对齐、涌现能力，大规模预训练与部署优化，以及偏见、攻击、法律等伦理安全话题。
- 作业/项目：共六次作业，覆盖预训练数据准备、Transformer 实现、检索增强生成、模型比较与偏见缓解、训练效率提升等；另有项目。
- 自学建议：课前指定论文要读，作业要动手实现模型；完整视频可能需 CMU 内部平台。
- 链接：https://cmu-llms.org/

### 1.3 CMU 11-711: Advanced Natural Language Processing (ANLP)

- 学校：Carnegie Mellon University
- 难度：★★★★☆
- 学时：约 100 小时（站内写 100 学时）
- 先修：无硬性要求；需 Python 编程经验、概率论与线性代数基础，有神经网络使用经验更佳
- 语言：Python
- 定位：研究生 NLP 入门与进阶课，从词表征、序列建模讲到注意力与 Transformer，再到大规模预训练、指令微调、复杂推理、多模态与安全性。
- 作业/项目：每次课配代码演示与在线小测；期末项目要复现并改进一篇前沿论文。
- 自学建议：按课前推荐文献顺序读，提前备好 PyTorch/Hugging Face 环境；课堂视频上传 Canvas，需 CMU 账号。
- 链接：https://www.phontron.com/class/anlp-fall2024/

### 1.4 CMU 11-868: Large Language Model Systems

- 学校：Carnegie Mellon University
- 难度：★★★★☆
- 学时：约 120 小时
- 先修：强烈建议先修 Deep Learning(11785) 或 Advanced NLP(11-611/11-711)
- 语言：Python
- 定位：从算法到工程搭 LLM 系统：GPU 编程与自动微分，分布式训练（ZeRO、FlashAttention、DDP、GPipe、Megatron-LM），压缩与加速（GPTQ、MoE、JAX/Triton、vLLM、CacheGen），以及 RAG、多模态、RLHF 与在线监控。
- 作业/项目：五次编程作业加期末大项目；A1 自动微分框架 + CUDA 手写算子 + 基础网络，A2 GPT2，A3 手写 CUDA 的 Softmax 与 LayerNorm 提速，A4 分布式训练（自学时环境不好配）。
- 自学建议：先配好支持 CUDA 的环境，复习并行计算与自动微分；实验有难度，不适合纯小白入手。
- 链接：https://llmsystem.github.io/llmsystem2025spring/

### 1.5 CMU 15-779: Advanced Topics in Machine Learning Systems (LLM Edition)

- 学校：Carnegie Mellon University
- 难度：★★★★☆（站内标 4/5）
- 学时：约 80–120 小时
- 先修：无硬性要求；建议有机器学习入门与深度学习训练经验、熟悉 PyTorch，懂 CUDA/GPU 基础会明显省力
- 语言：Python（系统与算子部分涉及 CUDA/硬件概念）
- 定位：从系统视角回答一个核心问题：高层框架写出的模型如何被分解为底层 kernel，并在异构加速器与分布式环境中高效执行。主题含 GPU 编程、ML 编译、图级优化、分布式与自动并行、LLM Serving 与推理加速。
- 作业/项目：持续完成课前论文阅读（paper review），并以小组完成期末系统项目（proposal、presentation、report）。
- 自学建议：当成「按周推进的系统训练营」来做，不要只看 slide；课程网站有每讲 slide 与阅读列表。
- 链接：https://www.cs.cmu.edu/~zhihaoj2/15-779/
