### 1.1 Stanford CS143: Compilers

- 学校：Stanford
- 难度：★★★★★
- 学时：约 150 小时
- 先修：计算机体系结构
- 语言：Java 或 C++
- 定位：为课程自研的 COOL 语言实现编译器，把 COOL 编译成 MIPS 汇编并在 Spim 模拟器上执行；理论按龙书顺序讲词法、语法、语义、运行时环境、寄存器分配、优化与代码生成。
- 作业/项目：5 个书面作业 + 5 个编程作业，编程分词法分析、语法分析、语义分析、代码生成四阶段，难度循序渐进，优化部分留了很大设计空间。
- 自学建议：理论与实践配比最均衡的编译课之一，适合当第一门编译原理；B 站有全套视频，需自备 MIPS 模拟器环境。
- 链接：http://web.stanford.edu/class/cs143/

### 1.2 CS420: Compiler Design

- 学校：KAIST
- 难度：★★★★
- 学时：约 80 小时
- 先修：数据结构、计算机系统基础、Rust 编程基础
- 语言：Rust
- 定位：在 KECC（KAIST Educational C Compiler）框架上做真实 C 语言编译器的中后端：语法树打印、SSA 中间代码生成、CFG 简化与 GVN 等优化、RISC-V 目标代码生成。
- 作业/项目：围绕 KECC 框架分阶段实验，第一个实验就直接从抽象语法树遍历开始；用 C 语言 Fuzzing 工具 Csmith 测试。
- 自学建议：前端理论讲得很少，不要求手写前端，不适合零编译基础者；想理解 LLVM 式 IR 设计/生成/优化，或想顺手练 Rust 的话性价比高，配套视频有逐段代码讲解。
- 链接：未标

### 1.3 NJU 编译原理

- 学校：南京大学
- 难度：★★★
- 学时：约 80 小时
- 先修：离散数学
- 语言：Java
- 定位：用 ANTLR 4 做词法/语法分析，先动手写小例子再补理论；理论部分按龙书节奏讲语义分析、运行时环境、寄存器分配、代码优化与生成。
- 作业/项目：10 个书面作业 + 8 至 10 个编程作业，由简到繁实现一个自己的编译器；Online Judge 与课程讨论（Zulip）对校外学生开放。
- 自学建议：难度最低、有 IDE 插件可视化语法树，适合入门编译；ANTLR 4 是 LL 解析器生成器，可处理语法范围比 LR/LALR 窄，靠无限长 token 超前扫描弥补，想深究 LR 理论要另补材料。
- 链接：http://docs.compilers.cpl.icu/

### 1.4 PKU 编译原理实践

- 学校：北京大学
- 难度：★★★★
- 学时：约 60 小时
- 先修：计算机系统基础、数据结构与算法、编程基础
- 语言：C/C++/Rust 任选其一
- 定位：把精简版 C 语言 SysY 编译到 RISC-V 汇编，从空文件夹开始写；配套自研中间表示 Koopa IR（形式类似 LLVM IR，但简化很多）。
- 作业/项目：保姆级文档把写编译器拆成 9 个小步骤，Docker 环境一键配置并带自动测试脚本；测试只检查输出汇编的正确性，不限制编译器设计与实现语言。
- 自学建议：最适合“零编译器基础但想真写出一个编译器”的人，反馈周期短，能编 Mandelbrot 集绘制程序和 Lisp 解释器这类真实程序；代价是 lexer/parser、IR 解析与生成交给工具，手写前端的功力要自己另补。
- 链接：未标（教程在 GitHub Pages，页面未给出 URL）

### 1.5 SJTU 编译原理

- 学校：上海交通大学
- 难度：★★★★
- 学时：约 150 小时
- 先修：计算机系统基础、数据结构与算法、编程基础
- 语言：C++
- 定位：实现 Tiger 语言编译器，覆盖词法分析、文法分析、语义分析、逃逸分析、活动记录（栈帧）、LLVM IR、活跃分析、寄存器分配、垃圾收集、面向对象与函数式程序。
- 作业/项目：2 次 Quiz + 5 个必做 Lab（直线程序解释器、Lexer、Parser、类型检查、逃逸分析 + 翻译到 LLVM）+ 2 个选做 Lab（代码生成、寄存器分配）；测试只看输出汇编的正确性。
- 自学建议：IPADS 实验室老师讲理论，实践自由度高、强度大；框架代码暂不开源（旧版见 gitee，新版需联系当届助教），自学要先解决框架来源，虎书（Modern Compiler Implementation in C）中文版是配套教材。
- 链接：https://ipads.se.sjtu.edu.cn/courses/compilers

### 1.6 USTC 编译原理

- 学校：中国科学技术大学
- 难度：★★★★
- 学时：约 100 小时
- 先修：数据结构、计算机系统基础、C++ 编程基础
- 语言：C++
- 定位：理论覆盖面广，既有词法、语法、语法制导翻译、中间代码翻译，也有运行时管理、机器无关与面向机器的代码优化；实验用 Cminusf 框架走完整流程。
- 作业/项目：6 个 Lab：Flex/Bison 写前端、生成 LightIR（LLVM 子集）中间代码、生成龙芯汇编、中间代码优化、机器无关优化、寄存器分配，配套脚本自动测试。
- 自学建议：课件、实验框架、教程全部开源，对初学者友好，难度循序渐进；用 LLVM 子集当中间代码而非玩具 IR，且后端生成与优化都覆盖，适合想一次走完编译全流程的人。
- 链接：未标
