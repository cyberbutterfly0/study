### 1.1 Stanford CS142: Web Applications

- 学校：Stanford
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：有一定的编程经验
- 语言：JavaScript/HTML/CSS
- 定位：Web 应用开发课，覆盖 HTML、CSS、JavaScript、ReactJS、NodeJS、ExpressJS、Web 安全等内容。
- 作业/项目：8 个 Project，在实战中练 Web 开发技巧，是这门课的主要训练量。
- 自学建议：页面未给课程官网与视频链接，按 Project 推进即可；先修只要求编程经验，适合边做边补前端语法。
- 链接：未标（页面未给出课程官网）

### 1.2 CS571: Building UI (React & React Native)

- 学校：威斯康星大学麦迪逊分校（University of Wisconsin, Madison）
- 难度：★★★☆☆
- 学时：每周 2 小时讲座 + 每周 4–10 小时作业，持续 12 周
- 先修：CS400（高级 Java），原文认为先修不必要，掌握至少一门编程语言即可
- 语言：JavaScript/HTML/CSS
- 定位：React 前端与 React Native 移动端开发的最佳实践介绍，用两门技术的最新版本，课程网站每学期更新；另讲 Dialog Flow 聊天机器人工具与 UX Design 实用原则。
- 作业/项目：作业量大，课上讲知识点但不手把手写代码；starter code 起点合适，不用为配 Node.js 环境伤脑筋。
- 自学建议：不是保姆课，写作业前先读 react.dev 相关章节；不要求预先会 JS/HTML/CSS，但课堂语法介绍有限，遇到语法问题要勤查；官网对所有人开放，可用邮箱申请 Badger ID。
- 链接：https://cs571.org

### 1.3 University of Helsinki: Full Stack open 2022

- 学校：University of Helsinki
- 难度：★★☆☆☆
- 学时：未标（原文写"因人而异"）
- 先修：良好的编程技能、基本网络编程与数据库知识，了解 Git 基础
- 语言：JavaScript/HTML/CSS/NoSQL/SQL
- 定位：用 JavaScript 开发现代 Web 应用，重点是用 ReactJS 构建单页应用、用 Node.js 构建 REST API，另含 GraphQL 作为 REST 的现代替代方案。
- 作业/项目：作业见课程网站，包含测试、配置与环境管理，以及用 MongoDB 存储应用数据。
- 自学建议：四门课里难度最低（2 星），有中文版站点，适合作为 Web 入门第一门；有 Discord 与 Telegram 群可问。
- 链接：https://fullstackopen.com/zh/

### 1.4 MIT Web Development Crash Course

- 学校：MIT
- 难度：★★★☆☆
- 学时：未标（原文写"因人而异"）
- 先修：掌握至少一门编程语言
- 语言：JavaScript/HTML/CSS/NoSQL
- 定位：MIT 每年 1 月 IAP 期间为期 4 周的课程，一个月里从零掌握网站的设计、搭建、美化、交互，基本覆盖前后端大部分技术栈。
- 作业/项目：作业见课程 Schedule，页面未列具体项目数量。
- 自学建议：适合不打算系统学 Web、只想把它加进技能包的人；强度集中在 4 周，节奏偏快。
- 链接：https://weblab.mit.edu/schedule/
