### 1.1 ETH: Computer Architecture（CA）

- 学校：ETH Zurich（Onur Mutlu 授课）
- 难度：★★★★☆
- 学时：约 70 小时以上
- 先修：DDCA
- 语言：C/C++、Verilog
- 定位：DDCA 的进阶课，讲类 MIPS 处理器的控制与数据通路、流水线与简单超标量、快速内存与存储系统，并覆盖 DRAM、非易失存储、存内计算、多核一致性与 GPU 等前沿方向
- 作业/项目：5 个 Project，大多与内存和 cache 相关；实验用 Verilog 做类 MIPS 流水线 CPU 的 RT 实现，另用 C 写周期精确的处理器模拟器探索设计选项
- 自学建议：比 CS61C 难，部分内容很前沿；无指定教材但每讲配大量文献，阅读量顶一学期讲座，建议先做 DDCA 实验补 Verilog 再上
- 链接：https://safari.ethz.ch/architecture/fall2022/doku.php?id=start （页面标注 2020 Fall、2022 Fall）

### 1.2 CS61C: Great Ideas in Computer Architecture

- 学校：UC Berkeley
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：CS61A、CS61B
- 语言：C
- 定位：CS61 系列最后一门，讲 C 如何一步步变成 RISC-V 汇编并在 CPU 上执行，涉及流水线、Cache、虚存与并发
- 作业/项目：4 个 Project：C 写小游戏（如 Game of Life）、RISC-V 汇编实现识别 MNIST 的神经网络、用 Logisim 搭二级流水线 CPU 跑 RISC-V 汇编、用 OpenMP 和 SIMD 优化矩阵运算做个简易 Numpy
- 自学建议：比 N2T 在难度和深度上高很多，别直接跳；要有 C 和汇编基础，Project3 从零搭 CPU 要留足时间
- 链接：https://cs61c.org/

### 1.3 DDCA: Digital Design and Computer Architecture

- 学校：ETH Zurich
- 难度：★★★☆☆
- 学时：约 100 小时
- 先修：CS50 或同阶课程，最好有 C 语言基础
- 语言：C、Verilog、MIPS 汇编、LC3 汇编
- 定位：从晶体管、逻辑门一直讲到微架构、缓存与虚拟内存，完全从计算机设计角度出发，并介绍体系结构领域最新研究
- 作业/项目：9 个 lab，用 Basys 3 FPGA 开发板（需自购）和 Xilinx Vivado，从组合、时序电路做到完整 CPU；除 lab 答案和当期考试答案外资料全部开源
- 自学建议：想学 CA 必须先过这门；学完能掌握 Verilog、MIPS 与 C 的对应关系、单周期/多周期/流水线 CPU 设计与性能分析
- 链接：https://safari.ethz.ch/digitaltechnik/spring2023/ （页面标注 2020、2023）

### 1.4 Nand2Tetris

- 学校：希伯来大学（Coursera）
- 难度：★★★☆☆
- 学时：约 40 小时
- 先修：无
- 语言：任选一个编程语言
- 定位：从与非门开始造一台计算机并在上面跑俄罗斯方块；硬件部分用 HDL 搭出 CPU 跑课程自定义汇编，软件部分写 Jack 编译器（到字节码再到汇编）和一个简易 OS
- 作业/项目：10 个 Project 造一台计算机，硬件与软件两部分衔接，官方定位是零基础、高中生也能懂
- 自学建议：最适合当体系结构的第一门，一个月内能学完；只讲本质、不陷于性能细节，学完再上 CS61C 或 DDCA
- 链接：https://www.coursera.org/learn/build-a-computer
