### 1.1 CS50: This is CS50x

- 学校：Harvard
- 难度：★★☆☆☆
- 学时：约 20 小时
- 先修：无
- 语言：C, Python, SQL, HTML, CSS, JavaScript
- 定位：哈佛全校公选课，Malan 授课、多年被学生评为最受欢迎的公选课；因为要面向非计算机专业，内容难度偏温和（课堂上撕黄页讲二分法），但作业质量高且全部免费开源。
- 作业/项目：页面只写「参考课程网站」，没有列具体的 project 数量；作业免费开源是这门课的主要卖点。
- 自学建议：最适合零基础起步，有基础的人当休闲课刷也行；视频在 B 站有中文字幕版。
- 链接：https://cs50.harvard.edu/x/

### 1.2 Introductory C Programming Specialization

- 学校：Duke
- 难度：★★★★☆
- 学时：约 110 小时
- 先修：无
- 语言：C
- 定位：Coursera 专项课，基础概念讲得透（frame、stack memory、heap memory），针对 C 里最难的指针配了大量练习；还带 GDB、Valgrind 和基本 Git 的上手训练。
- 作业/项目：作业以写 C 代码 + 用 GDB/Valgrind 调试为主，课程建议用 Emacs 写（Vim 用户可挂 Evil 插件）。
- 自学建议：课名虽叫入门，广度和深度都不小，110 小时是实打实的投入；课程可能需付费，作者认为值。
- 链接：https://www.coursera.org/specializations/c-programming

### 1.3 UCB: Sysadmin DeCal

- 学校：UCB
- 难度：★★★☆☆
- 学时：约 20 小时
- 先修：无
- 语言：shell
- 定位：十二周的 Linux 入门课：Linux 基础、shell 编程（含 tmux、vim）、包管理、服务、基础计算机网络、网络服务、安全与密钥管理、Git、Docker、Kubernetes、Puppet、CUDA。
- 作业/项目：作业见课程官网；部分练习（如 ssh）需要 UCB 内部账号登录远程服务器，其余可用自建虚拟机 + Xshell 或 Linux 桌面版完成。
- 自学建议：比定位相同的 MIT Missing Semester 更系统、更面向零基础，作者因此更推荐它；外校补不了远程机部分，可用 OverTheWire 的 bandit 前 15 关练命令行。
- 链接：https://csdiy.wiki/编程入门/DeCal/（页面「课程网站」只写了「官网」两个字，抓取时链接地址丢失）

### 1.4 CS3110: OCaml Programming Correct + Efficient + Beautiful

- 学校：Cornell
- 难度：★★★☆☆
- 学时：约 40 小时
- 先修：了解一门命令式编程语言（类 C 语言）
- 语言：OCaml
- 定位：页面把它称作「modern SICP」，讲 OCaml 基础、数据结构与算法、测试开发、形式证明、语言特性实现，各块内容递进互补而不是彼此割裂。
- 作业/项目：作业就是教材里的 exercises，难度分 1 到 4 星自选，3 星到 4 星之间跨度很大。
- 自学建议：主讲 Michael Ryan Clarkson 用词简单、表述清晰，开英文字幕基本不费力，也能拿来练听力；课程在康奈尔打磨了 20 余年，源头是 MIT 6.001。
- 链接：https://cs3110.github.io/textbook

### 1.5 Haskell MOOC

- 学校：University of Helsinki
- 难度：★★☆☆☆
- 学时：未标（页面写「因人而异」）
- 先修：无
- 语言：Haskell
- 定位：用刚够用的 Haskell 语法讲函数式编程的核心语义：纯函数、惰性求值、强类型与类型推断、柯里化、Monoid / Functor / Monad / Applicative，不陷进语言生态细节。
- 作业/项目：练习注释里有足够的提示，提交后会给出标准答案，还能在官方 Telegram 里提问；有编程经验的人 Part1 很简单，难度集中在 Part2 的十三章之后。
- 自学建议：适合想搞懂 Java Streams、JS Promises 这类东西「为什么存在」的人；作者明确不建议写作业时参考别人的实现。
- 链接：https://haskell.mooc.fi/

### 1.6 MIT 6.092: Introduction To Programming In Java

- 学校：MIT
- 难度：★★☆☆☆
- 学时：少于 15 小时
- 先修：无
- 语言：Java
- 定位：七节课，每节 1 小时 Lec 讲知识点 + 1 小时 Lab 写代码；内容包括 Java 编译原理、Hello world、八大基础类型、命名与缩进等代码风格、Eclipse warning 与 Assertion、Exception 调试。
- 作业/项目：Lab 的 assignment 不难，经常前一节的作业下一节 Lec 就讲了，不需要自己啃。
- 自学建议：一天差不多能学完，强度适合新手；Lec 和 Lab 的代码都得自己敲；想进阶接着上 MIT 6.005/6.031。
- 链接：https://ocw.mit.edu/courses/6-092-introduction-to-programming-in-java-january-iap-2010/

### 1.7 MIT-Missing-Semester

- 学校：未标（页面没写所属大学，课程即 MIT 的 Missing Semester）
- 难度：★★☆☆☆
- 学时：约 10 小时
- 先修：无
- 语言：shell
- 定位：「计算机教学中消失的一个学期」：shell 编程、命令行配置、Git、Vim、tmux、ssh 这些大学课堂不教但每个 CS 学生都要用的工具。
- 作业/项目：只有一些随堂小练习，没有大项目，具体见课程网站。
- 自学建议：计算机小白优先学，它基本覆盖了本书「必学工具」里绝大部分内容；北大图灵班的前沿计算实践也有配套中文资料。
- 链接：https://missing.csail.mit.edu/ ｜ 中文站：https://missing-semester-cn.github.io/

### 1.8 CS50P: Introduction to Programming with Python

- 学校：Harvard University
- 难度：★★☆☆☆
- 学时：页面写 30-40 hours
- 先修：无
- 语言：Python
- 定位：CS50 的番外篇，仍是 David J. Malan 讲；覆盖 Python 基础与进阶语法、各种 Pythonic 的写法，对 Python 特色的标准库、代码测试、异常处理讲得比较深。
- 作业/项目：按 2022 版课程网站的 problem sets 走，页面未列具体项目。
- 自学建议：不需要任何编程基础，讲得平易近人，想快速入门 Python 的各阶段学生都能直接上。
- 链接：https://cs50.harvard.edu/python/

### 1.9 CS61A: Structure and Interpretation of Computer Programs

- 学校：UC Berkeley
- 难度：★★★☆☆
- 学时：约 50 小时
- 先修：无
- 语言：Python / Scheme / SQL
- 定位：CS61 系列第一门，主题是抽象：函数式编程、数据抽象、面向对象，目的是让代码更易读更模块化；不止教语言，还深入程序构造与运行的原理。
- 作业/项目：共 4 个 project，最后一个是用 Python 实现一个 Scheme 解释器。
- 自学建议：完全零基础直接上手对学习能力和自律要求不低，作者建议先学伯克利 CS10 或哈佛 CS50，避免被难度打击信心。
- 链接：https://cs61a.org/

### 1.10 MIT 6.100L: Introduction to CS and Programming using Python

- 学校：MIT
- 难度：★★☆☆☆
- 学时：约 50 小时以上（页面写 50h+）
- 先修：无
- 语言：Python
- 定位：MIT 2022 年课程改革后 EECS 的入门必修编程课（与 6.100A 二选一），覆盖 6.100A 全部内容：计算基本概念、Python、简单算法与数据结构、测试与调试、算法复杂度。
- 作业/项目：共 26 节课，官网把所有材料分好类，答案齐全，只有 Problem Sets 不给答案。
- 自学建议：Ana Bell 讲解深入浅出，难度曲线平滑，适合零基础循序渐进；上课前先把当节课的代码下好，跟着一起敲。
- 链接：https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-22/

### 1.11 CS110L: Safety in Systems Programming

- 学校：Stanford
- 难度：★★★☆☆
- 学时：约 30 小时
- 先修：最好有一定的编程背景，并对计算机系统有初步认识
- 语言：Rust
- 定位：借 Rust 讲系统编程的安全性：在 C 的高效之上补掉内存泄漏和裸指针的危险；后半程专讲并发（多进程、多线程、事件驱动），并在第二个 project 里比较几种并发技术各自的优劣。
- 作业/项目：6 个 Lab + 2 个 Project，两个 project 分别是用 Rust 写一个类似 GDB 的 debugger、写一个负载均衡器。
- 自学建议：2022 年课程没开源作业源码，2020 版项目依赖的库已随 Rust 演进而过时，需要自己动手适配（社区有 2022 年的适配版）；Rust 语法可配合 CS242 Fall2019 第 6-9 周补。
- 链接：https://reberhardt.com/cs110l/spring-2020/

### 1.12 CS220: Programming Principles

- 学校：KAIST
- 难度：★★★☆☆
- 学时：约 40 小时
- 先修：会其他任何一门编程语言
- 语言：Rust
- 定位：Jeehoon Kang 与其实验室做的 Rust 入门课，覆盖 Rust 入门所需的绝大多数知识点；没有官方教材，课程主页推荐用 Rust book 学，slides 里给了大致学习线路。
- 作业/项目：没有公开教学视频，但测试系统完善，可以当 Rust 习题课来练手，部分习题能作为 CS110L 的补充，也有一部分确实有难度。
- 自学建议：适合学完 CS110L 还觉得练习不够的人；网上没有公开参考答案，卡住可以去课程的 ISSUE 里翻讨论；主讲人对用 AI 辅助编程持鼓励态度，但核心工作仍要自己完成。
- 链接：https://github.com/kaist-cp/cs220

### 1.13 CS431: Concurrent Programming

- 学校：KAIST
- 难度：★★★★☆
- 学时：约 50 小时
- 先修：Rust 编程基础 + 对并发的初步了解
- 语言：Rust
- 定位：并发编程课，理论部分建立并发情形下的编程模型（promising semantics、访存模型），实践部分理解 Rust 相关库中锁与无锁数据结构的实现原理。
- 作业/项目：代码量不大但不简单，从基于锁的并发安全缓存、链表，做到无锁哈希表和 hazard pointer，配详细的本地测试。
- 自学建议：比预想中深得多，自旋锁、互斥锁在这门课里只是最基础的部分；页面没有给课程资源链接。
- 链接：https://github.com/kaist-cp/cs431（页面未给链接，按同实验室 cs220 仓库推得）

### 1.14 Amirkabir University of Technology 1400-2: Advanced Programming Course

- 学校：Amirkabir University of Technology
- 难度：★★★★★
- 学时：约 50 小时
- 先修：无
- 语言：C++
- 定位：作者无意中发现的 C++ 课，homework 质量高、彼此独立、结构简单，并且带完善的单元测试，适合拿来做 C++ 练习。
- 作业/项目：共 7 个 homework：实现 Matrix 类、模拟加密货币客户端/服务端、实现 BST、实现 SharedPtr 与 UniquePtr、用继承和多态写多个类、用 STL 解 4 个问题，外加一个 Python 项目。
- 自学建议：找不到课程主页，也没有教材，只有 GitHub 上的 homework 源码（AP1400-2-HW 那几个仓库），基本靠自己读题 + 跑测试来学。
- 链接：https://github.com/courseworks

### 1.15 Stanford CS106B/X: Programming Abstractions in C++

- 学校：Stanford
- 难度：★★☆☆☆
- 学时：约 50-70 小时
- 先修：计算机基础（CS50 / CS106A / CS61A 或同等水平）
- 语言：C++
- 定位：Stanford 的进阶编程课，CS106X 比 CS106B 更难更深但主体内容相同；讲 collections、ADT、递归、BFS、DFS、回溯、排序、哈希、指针、链表、BST、OOP、值传递与引用传递、栈分配与堆分配、内存管理。
- 作业/项目：每个作业都有 starter code、详细文档和测试程序，按 milestone 一步步做，做完能在给出的 GUI 里看到自己的数据结构跑起来；assignment8 要在 debugger 里读状态逃出迷宫，最后用 huffman 编码压缩和解压文件。
- 自学建议：作业版本不兼容的问题见仓库 readme；视频推荐 YouTube 上 spring 2015 那版，老师有激情、课堂提问环节有料。
- 链接：https://web.stanford.edu/class/cs106b/

### 1.16 CS106L: Standard C++ Programming

- 学校：Stanford
- 难度：★★★☆☆
- 学时：约 20 小时
- 先修：最好掌握至少一门编程语言
- 语言：C++
- 定位：专讲标准 C++ 的特性与语法：auto binding、uniform initialization、lambda、move semantics、RAII 等，目标是摆脱「C 语言 + cin/cout」式的写法。
- 作业/项目：两个作业：实现 WikiRacer 小游戏、实现一个类似 STL 的 HashMap（近似 unordered_map），其中 iterator 的实现最难，也是把整门课串起来的那一环。
- 自学建议：课本身不难但信息量大，得在之后的开发里反复用才记得住；Stanford 后面的 CS144、CS143 等项目都用 C++，学它是为那些课铺路。
- 链接：http://web.stanford.edu/class/cs106l/
