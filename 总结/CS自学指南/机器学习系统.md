### 1.1 智能计算系统（AICS）

- 学校：中国科学院大学
- 难度：★★★☆☆
- 学时：约 100 小时以上
- 先修：体系结构、深度学习
- 语言：Python、C++、BCL
- 定位：陈云霁开设，用一系列实验串起完整的 AI 技术栈：上层深度学习框架、底层算子编写、再到硬件中 MLU 的设计。
- 作业/项目：旧版 6 个实验，包括编写卷积算子、为 TensorFlow 添加算子、用 BCL 写算子并集成进 TensorFlow；2024 新版全面改用 PyTorch，不再用 TensorFlow，并加入大模型相关实验。
- 自学建议：站内作者做了第 2、3、4、5 个实验，综合实验与硬件实验没做；他认为第三章实现算子的实验最能加深对框架的理解，第五章 BCL 写算子对熟悉 CUDA 的人很亲切。熟悉深度学习可直接从第五章看起，建议配一本教材。
- 链接：未标（站内只以「官网」文字给出，未展开地址）

### 1.2 CMU 10-414/714: Deep Learning Systems

- 学校：CMU
- 难度：★★★☆☆
- 学时：约 100 小时
- 先修：系统入门（如 15-213）、深度学习入门、基本数学知识
- 语言：Python、C++
- 定位：深度学习系统全栈：框架顶层设计、自动微分原理与实现、底层硬件加速、生产部署。
- 作业/项目：5 个作业从零实现完整深度学习库 Needle，要支持计算图自动微分、GPU 硬件加速、各类损失函数/数据加载器/优化器，再实现 CNN、RNN、LSTM、Transformer。
- 自学建议：课程循序渐进，复杂网络都配 jupyter notebook 讲实现细节；有基础可在自微分部分之后直接上手作业。两位老师已开源全部课程内容，但在线评测账号与课程论坛注册已结束，只剩框架代码里的本地测试。

### 1.3 CMU 15-442/642: Machine Learning Systems

- 学校：CMU
- 难度：★★★★☆
- 学时：约 100 小时以上
- 先修：系统入门（如 15-213）、深度学习入门、基本数学知识
- 语言：Python、C++、CUDA(PTX)、TIRx
- 定位：以「模型、数据、系统、硬件」全栈视角讲 LLM 时代的训练与部署：自动微分、Blackwell B200 级 GPU 编程、ZeRO 与张量/流水线并行、连续批处理/PagedAttention/投机解码、ML 编译与 Mega-Kernel。
- 作业/项目：3 个作业，一是扩展图自动微分框架；二是用 MPI 和 NumPy 实现 ZeRO Stage 3 参数分片与张量模型并行的通信逻辑；三是用 TIRx DSL 在 B200 上手写并优化 FP16 矩阵乘，处理 128B Swizzle、TMA 异步搬运、Warp Specialization 与 2-CTA 集群，把算力从 0.02 TFLOP/s 提到 1300+ TFLOP/s。
- 自学建议：作业硬核且贴着工业前沿，按框架、分布式、GPU 算子三级递进；想搞清 vLLM、SGLang 底层原理的适合选它，但要先有 GPU 与系统基础。
- 链接：未标（站内「课程资源」段为空）

### 1.4 CSE234: Data Systems for Machine Learning

- 学校：UCSD
- 难度：★★★☆☆
- 学时：约 120 小时
- 先修：线性代数、深度学习、操作系统、计算机网络、分布式系统
- 语言：Python、Triton
- 定位：以 LLM 系统为核心的三段式课程：现代深度学习与计算图基础；GPU、CUDA、Triton、图优化、内存、量化等系统优化；并行策略与 LLM 训练推理。
- 作业/项目：作业直接面对内存带宽、通信开销、kernel fusion 等性能瓶颈，用 Triton 或系统级优化解决；在线测评与参考答案未开源。
- 自学建议：前期对系统与并行计算背景要求较高，建议提前补 CUDA 与并行编程；基础部分可配 micrograd，系统与 LLM 部分可配 nanoGPT、nano-vllm。
- 链接：https://hao-ai-lab.github.io/cse234-w25/

### 1.5 MIT 6.5940: TinyML and Efficient Deep Learning Computing

- 学校：MIT
- 难度：★★★★☆
- 学时：约 50 小时
- 先修：体系结构、深度学习基础
- 语言：Python
- 定位：Song Han 的高效训练与推理课，三部分：剪枝/量化/蒸馏/网络架构搜索，LLM 推理与长上下文、后训练加速、多模态、GAN、扩散模型，以及分布式并行、自动并行优化、梯度压缩、边缘训练。
- 作业/项目：5 个实验，前三个分别考察量化、剪枝、NAS，后两个是 LLM 压缩与高效部署；总体难度相对简单，但能巩固核心知识。
- 自学建议：想先了解大模型可重点看第二、三部分；视频有油管官方版，B 站也有搬运。
- 链接：未标（站内以「2024fall、2023fall」文字给出）

### 1.6 Machine Learning Compilation

- 学校：Bilibili 大学（陈天奇 2022 年暑期在线课）
- 难度：★★★☆☆
- 学时：约 30 小时
- 先修：机器学习/深度学习基础
- 语言：Python
- 定位：以 Apache TVM 为例讲机器学习编译：把 TensorFlow、PyTorch、JAX 里的模型，经一套普适抽象与优化算法，变换成高性能、适配各类硬件的部署形态。
- 作业/项目：没有单独作业，每节课配一个 Jupyter Notebook，用具体代码讲知识点；中英文资源全部开源。
- 自学建议：这个方向此前没有专门课程，想建立全貌可以学；讲的是高层宏观概念，做 TVM 开发时可当规范代码示例库。
