### 1.1 CS242: Programming Languages

- 学校：Stanford
- 难度：★★★★
- 学时：约 60 小时
- 先修：对计算机系统和编程语言理论有初步了解
- 语言：OCaml、Rust
- 定位：先讲 Lambda 演算与类型系统，再用 OCaml/Rust 的实际编程把理论落到“怎么帮开发者避免错误”；主讲 Will Crichton 把这套思路写成论文 From Theory to Systems。
- 作业/项目：约 8 次作业，从 JSON 形式化与证明、Lambda 演算、OCaml 函数式入门、用 OCaml 写类型检查器与解释器，到 WebAssembly、线性类型与 Rust 所有权、Rust 异步、状态机与 session-typed TCP 库；大作业 4 选 1（Lean 定理证明、Rust 实现 Read-Log-Update、F* 验证文件系统、OCaml 写深度学习框架），后者有 200 多个测试。
- 自学建议：无课程视频，靠课程笔记与作业自学；前几次偏 PL 理论、后几次偏系统编程，嫌理论虚就重点做 OCaml 解释器那个作业；作业整体偏难，卡住属正常，重读实验指导。
- 链接：未标

### 1.2 Cambridge: Semantics of Programming Languages

- 学校：University of Cambridge
- 难度：★★★
- 学时：约 20 至 30 小时
- 先修：基础离散数学
- 语言：OCaml/ML
- 定位：编程语言语义学入门，从 BNF 定义的简单命令式语言的操作语义讲起，经形式类型系统与结构归纳法证明，到指称语义、子类型与函数、语义等价性、一致性与并发语义。
- 作业/项目：作业不公开，只有考试真题的相关题目汇总公开，Cambridge 内部 supervision 作业及全部答案均不公开。
- 自学建议：20-30 小时的轻量理论课，校内面向二年级，是少数提供公开视频的编程语言理论课；要害是没作业可练，想巩固得自己照 TAPL 与 Winskel 的书补证明。
- 链接：未标

### 1.3 NJU 软件分析

- 学校：南京大学
- 难度：★★★
- 学时：约 60 小时
- 先修：数据结构与算法，至少熟悉一门编程语言
- 语言：Java
- 定位：静态分析的理论与实践，即不运行程序、只分析源码及各种表示来近似判定程序性质；从抽象语法树、控制流图、中间表示讲起，到数据流分析与指针分析，再到 IFDS 等高级主题。
- 作业/项目：作业基于自研 Java 框架“太阿”，8 个作业涵盖活跃变量分析、常量传播、死代码检测、程序调用图构建、上下文敏感与非敏感指针分析、污点分析；在线评测系统对所有人开放。
- 自学建议：作业本质是把课上伪代码实现出来，难度不大，适合听完课就练手；但通过每个作业的全部测试点很难。两位老师讲得细，课上会一步步走算法流程。
- 链接：未标

### 1.4 PKU 软件分析技术

- 学校：北京大学
- 难度：★★★★
- 学时：约 60 小时
- 先修：数据结构与算法，至少熟悉一门编程语言
- 语言：Java、Python
- 定位：熊英飞老师授课，覆盖面比南大版更全：基于抽象解释的程序分析（数据流分析、过程间分析、指针分析、抽象解释）、基于约束求解的程序分析（SAT、SMT、符号执行）、软件分析应用（程序合成、缺陷定位、缺陷修复）。
- 作业/项目：课程项目是实现一个 Java 上的指针分析系统和一个程序合成工具。
- 自学建议：理论更全、难度更大，适合先做过一遍南大软件分析、再补约束求解与程序合成的人；主要学习途径是听课，2020 年课程有燕云直播录像。
- 链接：未标
