### 1.1 CMU 17-803: Empirical Methods

- 学校：CMU
- 难度：★★★☆☆
- 学时：约 100 小时
- 先修：为从事软件工程实证研究的博士生开设，无硬性先修要求，但最好有一定的计算机基础
- 语言：不限
- 定位：Bogdan Vasilescu 讲授，专攻相对"陌生"的领域——软件工程实证研究，覆盖访谈、定性编码、调查设计等多种定性与定量研究方法，以及多种数据统计分析方法；还会讲如何挖掘整合 GitHub 与 Stack Overflow 等软件仓库中的数据，并运用统计建模、社交网络分析。
- 作业/项目：页面未标具体作业形式；课程用到的所有资源汇总在 GitHub 仓库 bvasiles/empirical-methods。
- 自学建议：这是为科研方向准备的课，不是练写代码的软件工程课。想评估新算法/新框架、分析从业者面临的挑战、做软件工程实证研究的人值得作为入门；只想提升工程能力的人应选其他课。
- 链接：未标（页面未给课程官网）

### 1.2 MIT 6.031: Software Construction

- 学校：MIT
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：掌握至少一门编程语言
- 语言：Java
- 定位：目标是写出高质量代码，三个判据由课程设计者原话给出：Safe from bugs（当下的正确性＋面向未来的防御性）、Easy to understand（代码要对未来读它、改它的人可读）、Ready for change（设计要经得起变化，而不是一改就推翻重写）。为此专门写了一本书讲软件构建的核心原则，细到注释与函数 Specification 怎么写、抽象数据结构怎么设计、并行编程怎么处理。
- 作业/项目：4 个编程作业 + 1 个 Project，用精心设计的 Java 项目练习上述模式；2016 年春季学期开源了全部编程作业的代码框架，无课程视频，教材即课程网站的 notes。
- 自学建议：适合已会一门语言、想系统纠正代码设计习惯的人，是"从能跑就行到看得下去"的分水岭课程。做法上先读 notes 对应章节再写作业，Specification 与抽象函数（AF/RI）那几节不要跳。
- 链接：未标具体 URL（页面只给 latest、Spring 2022、Spring 2021、Spring 2016 四个版本入口）

### 1.3 UCB CS169: software engineering

- 学校：UC Berkeley
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：无
- 语言：Ruby / JavaScript
- 定位：与强调类图、文档设计（plan and document 模式）的传统软件工程课不同，这门课专注敏捷开发（Agile Development），并用云平台提供软件即服务（SaaS）。设计者写了《Software as a service》教材，用 Ruby/Rails 阐释 SaaS 概念。
- 作业/项目：丰富的配套编程练习，按教材顺序一步步以敏捷开发方式搭出一个软件并免费部署到云平台上；完整资料在 edX 平台开源的 Agile SaaS Development 课程中，作业参见 edX 课程主页。
- 自学建议：适合想体验"从零到部署上线"全流程的人，跟着教材顺序做即可；Ruby/Rails 技术栈偏老但敏捷流程与 SaaS 部署思路仍通用。不适合想学类图与文档驱动方法的人。
- 链接：http://www.saasbook.info/courses
