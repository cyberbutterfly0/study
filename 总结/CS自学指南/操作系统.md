### 1.1 CS162: Operating System

- 学校：UC Berkeley
- 难度：★★★★★★（页面标注 6 星）
- 学时：约 200 小时+，上不封顶
- 先修：CS61A、CS61B、CS61C，扎实的 C 语言能力及 GDB 调试能力
- 语言：C、x86 汇编
- 定位：以教材 Operating Systems: Principles and Practice（第 2 版，四卷）补理论，配 Pintos 教学 OS 做设计实现，后半程讲虚拟内存与文件系统。
- 作业/项目：3 个 Project（User Programs、Threads、File Systems，各有完整本地测试）+ 6 个 Homework；框架代码极少，总代码量约 2000 行，3-4 人组队时后两个 Project 人均 40 小时以上。
- 自学建议：全书最重的操统课之一，不宜作第一门系统课；一个人自学 workload 明显大于组队要求，先读教材再动 Project，GDB 调试能力是硬门槛。
- 链接：未标（页面“课程网站”一栏未给出可读 URL）

### 1.2 HIT OS

- 学校：哈尔滨工业大学
- 难度：★★★★
- 学时：约 100 小时+
- 先修：C 语言
- 语言：C 语言、汇编
- 定位：李治军老师的中文课，基于 Linux 0.11 真实源码（约两万行）讲 CPU 管理、进程、内存管理与文件系统，强调必须动手做实验。
- 作业/项目：8 个小实验 + 4 个大实验，全部围绕 Linux 0.11 内核代码。
- 自学建议：中文授课、先修门槛低，适合当第一门操统课；坑在 Linux 0.11 是早期工业代码而非教学代码，实验里会撞上对理解 OS 没帮助的晦涩原生代码。
- 链接：未标

### 1.3 MIT 6.1810（原 6.S081）

- 学校：麻省理工学院
- 难度：★★★★★
- 学时：约 150 小时
- 先修：体系结构 + 扎实的 C 语言功底 + RISC-V 汇编语言
- 语言：C、RISC-V
- 定位：围绕 RISC-V 教学 OS xv6，带着源码讲 OS 机制与设计细节，而不是停在理论；2022 年秋起编号由 6.S081 改为 6.1810，内容不变。
- 作业/项目：11 个 lab，每周一个，逐个给 xv6 加新机制，测试框架完善（有的测试代码上千行）；后半程读文件系统、系统安全、网络、虚拟化等方向的经典论文。
- 自学建议：学过体系结构后可作为操统主线，lab 质量高、成就感强；RISC-V 汇编不熟会卡在 lab 开头，官方教材（xv6 book）要跟着读。
- 链接：https://pdos.csail.mit.edu/6.828/2021/schedule.html

### 1.4 NJU OS

- 学校：南京大学
- 难度：★★★★
- 学时：约 150 小时
- 先修：体系结构 + 扎实的 C 语言功底
- 语言：C 语言
- 定位：蒋炎岩老师授课，先从“程序就是状态机”讲并发控制与并发 bug，再把 OS 拆成进程/线程、地址空间、文件、设备等对象加系统调用，最后从 1-bit 存储介质推到文件系统。
- 作业/项目：5 个 MiniLab + 4 个 OSLab；MiniLab 都能本地测试，评测机不对校外开放。
- 自学建议：视角独特、Hacker 风格重，适合已有一门操统基础后补并发与持久化；第二个协程实验不到百行，但上下文切换要真理解。没有评测机不影响 MiniLab 自学。
- 链接：未标
