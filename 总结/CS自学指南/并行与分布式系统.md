# 并行与分布式系统

### 1.1 CMU 15-418 / Stanford CS149: Parallel Computing

- 学校：CMU（15-418）与 Stanford（CS149）
- 难度：★★★★★
- 学时：约 150 小时
- 先修：计算机体系结构，熟悉 C++
- 语言：C++
- 定位：讲现代并行计算架构的设计原则与必要权衡，学会用 CUDA、MPI、OpenMP 等框架写高性能并行程序；涉及高级体系结构与网络通信，知识点底层硬核。
- 作业/项目：5 个编程作业，分析并行程序瓶颈、写多线程同步代码、CUDA、OpenMP，以及 Spark 框架，强度大；原文提到 15-418 内容更丰富且有录播，CS149 作业更"fashion"。
- 自学建议：原作者看的是 15-418 录播、做的是 CS149 作业，可照此组合；体系结构不熟会很吃力，先补先修。
- 链接：https://gfxcourses.stanford.edu/cs149/fall21

### 1.2 MIT 6.5840（原 6.824）: Distributed System

- 学校：MIT
- 难度：★★★★★★（原文标六星，超出五星制）
- 学时：约 200 小时
- 先修：计算机体系结构，并行编程
- 语言：Go
- 定位：每节课精读一篇分布式系统经典论文，由此讲设计与实现的原则和关键技术；2023 年春季起编号由 6.824 改为 6.5840，内容不变。
- 作业/项目：5 个循序渐进、以难度大闻名的 Project，实现基于 Raft 共识算法的 KV-store 框架，在 debug 里体会分布式系统的随机性与复杂性。
- 自学建议：原文明确提醒网上答案无数，不要参考，自己实现整个 Project；卡住时可读 OneSizeFitsQuorum 的 Lab 文档，另有中文翻译视频。
- 链接：https://pdos.csail.mit.edu/6.5840/schedule.html
