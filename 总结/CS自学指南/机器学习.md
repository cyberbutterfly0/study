### 1.1 CS189: Introduction to Machine Learning

- 学校：UC Berkeley
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：CS188、CS70
- 语言：Python
- 定位：伯克利的机器学习导论，站内评价是讲得相当理论且深入，课程 notes 可以当工具书随时查。
- 作业/项目：全部 homework 代码与 Gradescope autograder 开源，比 CS229 更适合自学自测；具体作业数量未标。
- 自学建议：站内作者本人没有系统上过，只把 notes 当工具书查阅；想动手就借开源的 homework 加 autograder 自测，理论深度按研究生课预期。
- 链接：未标（站内未给课程网站）

### 1.2 CS229: Machine Learning

- 学校：Stanford
- 难度：★★★★☆
- 学时：约 100 小时
- 先修：高数、概率论、Python，需要较深厚的数学功底
- 语言：无（站内标「无」）
- 定位：吴恩达的研究生机器学习课，比 Coursera 版本更偏数学理论，讲算法本质而不是调包。
- 作业/项目：不对公众开放
- 自学建议：适合不满足于调包、想深入理解算法本质或做机器学习理论研究的同学；全部课程 notes 公开且写得专业，代价是需要数学功底。
- 链接：http://cs229.stanford.edu

### 1.3 Coursera: Machine Learning

- 学校：Stanford（Coursera 平台）
- 难度：★★★☆☆
- 学时：约 100 小时
- 先修：AI 入门 + 熟练使用 Python
- 语言：Python
- 定位：吴恩达的机器学习入门慕课，覆盖线性回归、逻辑回归、支持向量机、无监督学习、降维、异常检测、推荐系统。
- 作业/项目：保姆级代码框架，作业背景多取自生活场景，边学边编程。
- 自学建议：对新手极其友好，但数学推导多是一带而过；想深究理论转 CS229 或 CS189。新版已拆成三门课的系列，可在 Coursera 申请助学金后不订阅学习。
- 链接：https://www.coursera.org/specializations/machine-learning-introduction
