### 1.1 UCB CS161: Computer Security

- 学校：UC Berkeley
- 难度：★★★★★
- 学时：约 150 小时
- 先修：CS61A、CS61B、CS61C
- 语言：C、Go
- 定位：内容分五部分：安全原则（如何设计安全系统）、内存安全（缓冲区溢出攻击）、密码学（对称与非对称加密、MAC、数字签名）、Web（SQL 注入、XSS、XSRF）、网络各层攻击。
- 作业/项目：7 个在线 HW + 3 个 Lab + 3 个 Project；Project2 用 Go 设计和实现一个安全的文件分享系统，原文作者花了整整三天、代码量超过 3k 行。
- 自学建议：先修是三门 61 系列课，缺一不可；Project 强度极高，要留整块时间；2020 夏季学期版本开源了课程录影。
- 链接：https://su20.cs161.org/

### 1.2 ASU CSE365: Introduction to Cybersecurity

- 学校：Arizona State University
- 难度：★★★★☆
- 学时：未标（原文写"因人而异"）
- 先修：无
- 语言：C、Python、x86 汇编
- 定位：网络安全导论课，模块化组织：程序滥用（Linux 命令行、提权）、Web 基础（http、服务器、拦截）、汇编（寄存器、内存、控制流）、密码学（对称/非对称加密、哈希、信任）、Web 安全（命令注入、HTML 注入、SQL 注入、栈注入）。
- 作业/项目：8 个模块共 444 个 challenge，以 CTF 形式展开、难度依次递增；课程以 Challenge 为主、讲座与阅读为辅。
- 自学建议：不要求先修，但基础较弱卡关是正常现象，可去课程首页 Chat 栏目的 Discord 求助；官方不鼓励上传解题思路，每个模块前两题除外。
- 链接：https://pwn.college/cse365-s2025/

### 1.3 ASU CSE466: Computer Systems Security

- 学校：Arizona State University
- 难度：★★★★★
- 学时：未标（原文写"因人而异"）
- 先修：无
- 语言：C、Python、x86 汇编
- 定位：系统安全核心课，模块包括 Linux 命令行（程序滥用、程序交互）、Shellcoding（汇编、shellcode 注入与防御）、逆向工程（函数栈帧、静态/动态逆向工具）、程序利用（劫持到 shellcode、JIT spray）、系统利用（内核模块、提权）、杂项（沙箱、内存错误、竞态条件）。
- 作业/项目：13 个模块共 358 个 challenge，同样是 CTF 形式、难度递增；原文提到部分模块很难，尤其涉及内核的部分，有时一天写不出一道题。
- 自学建议：比 CSE365 更硬，建议先有 365 的汇编与 Web 基础再来；有 YouTube 讲座、Twitch 直播与 Discord；官方不鼓励上传解题思路，前两题与逆向部分 16 题除外。
- 链接：https://dojo.pwn.college/cse466/

### 1.4 MIT 6.1600: Foundations of Computer Security

- 学校：MIT
- 难度：★★★☆☆
- 学时：约 50 小时
- 先修：离散数学、编程基础、计算机系统基础
- 语言：Python3
- 定位：本科生系统安全课，分 authentication、transport security、platform security、software security、human/end-user security 五个模块，从认证与传输加密讲到代码执行平台与隐私安全，覆盖公私钥加密、哈希、电子签名、密钥交换等基本概念。
- 作业/项目：6 个实验，难度适中，通过编程实现漏洞利用来加深理解。
- 自学建议：数学与定理证明部分稍复杂枯燥，但会结合真实漏洞案例讲解；50 小时量级，适合作为安全方向第一门系统课。
- 链接：未标（页面仅给出 fall23 / fall22 两个版本的链接文字）

### 1.5 MIT 6.858: Computer System Security

- 学校：MIT
- 难度：★★★★★
- 学时：约 150 小时
- 先修：计算机体系结构，对计算机系统有初步了解
- 语言：C、Python
- 定位：MIT 的计算机系统安全课，实验环境是一个名为 Zoobar 的 Web 应用，学习攻防技术并把它应用到该应用上。
- 作业/项目：4 个 Lab（用缓冲区溢出攻击破坏 Zoobar 的安全属性、用权限分离改进 Zoobar、基于符号执行构建程序分析工具找 Python bug、防御浏览器攻击）+ Final Project 实现 SecFS（面对完全不可信的服务器提供机密性与完整性，参考论文 SUNDR）。
- 自学建议：原文作者主要做 Lab 3，认为理解符号执行思想后 Lab 并不难；Final Project 要先读懂 SUNDR；建议有 C 与系统基础再开始。
- 链接：http://css.csail.mit.edu/6.858/2022/

### 1.6 SEEDLabs

- 学校：雪城大学
- 难度：★★★★☆
- 学时：约 150 小时
- 先修：未标
- 语言：C、汇编
- 定位：由 NSF 提供 130 万美元资金支持开发的网安动手实验体系，理论教学与动手实践并重，覆盖软件安全、网络安全、Web 安全、操作系统安全和移动应用安全，目前全球 1050 家研究机构在使用。
- 作业/项目：40 多个安全领域 lab，配开源讲义、视频教程、多语种教材，以及开箱即用的虚拟机和 docker 攻防环境，每个 lab 有原理讲解与实验指导。
- 自学建议：环境现成，适合边做边学；可从缓冲区溢出实验入手，它属于软件安全主题，有配套实验指导与教材章节。
- 链接：https://seedsecuritylabs.org/index.html
