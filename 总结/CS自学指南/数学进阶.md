### 1.1 MIT 6.042J: Mathematics for Computer Science

- 学校：MIT
- 难度：★★★☆☆
- 学时：约 50-70 小时
- 先修：微积分、线性代数
- 语言：Python（页面写 Python preferred）
- 定位：MIT 的离散数学加概率综合课，主讲是 Tom Leighton（Akamai 联合创始人之一）；学完对后续算法学习大有裨益。
- 作业/项目：作业参考课程网站（spring2015 / fall2010 / fall2005 三个版本），页面未列具体数量。
- 自学建议：先修只有微积分和线代，可作为算法课前置；B 站有 spring2015 与 fall2010 两版视频，跟着哪版看哪版即可。
- 链接：https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/

### 1.2 UCB CS126: Probability theory

- 学校：UC Berkeley
- 难度：★★★★★
- 学时：约 100 小时
- 先修：CS70、微积分、线性代数
- 语言：Python
- 定位：伯克利的概率论进阶课，涉及统计学、随机过程等相对深入的内容，需要相当数学基础；页面作者自述学的时候也感到吃力。
- 作业/项目：14 个书面作业 + 9 个编程作业；配套教材 Probability in Electrical Engineering and Computer Science 全书开源，每章以一个具体算法为例（PageRank、路径规划、语音识别等），配套 Python 实现以 Jupyter Notebook 在线发布，可改可跑。
- 自学建议：不是概率入门课，要先过 CS70 与微积分、线代；强调理论结合实践，建议边看教材边跟着 Notebook 跑例子。
- 链接：https://inst.eecs.berkeley.edu/~ee126/fa20/content.html

### 1.3 UCB CS70: discrete Math and probability theory

- 学校：UC Berkeley
- 难度：★★★☆☆
- 学时：约 60 小时
- 先修：无
- 语言：无
- 定位：伯克利的离散数学入门课，亮点是每个模块都把理论对应到实际算法：逻辑证明对稳定匹配、图论对网络拓扑设计、基础数论对 RSA、多项式环对纠错码、概率论对哈希表与负载均衡。
- 作业/项目：作业见课程 Schedule，教材即课程 notes，页面未列具体数量。
- 自学建议：无先修可入门，notes 公式推导与实例都多、阅读体验好；是 CS126 和 CS170 的先修，建议早学。
- 链接：http://www.eecs70.org/

### 1.4 The Information Theory, Pattern Recognition, and Neural Networks

- 学校：Cambridge
- 难度：★★★☆☆
- 学时：约 30-50 小时
- 先修：微积分、线性代数、概率统计
- 语言：不限，Python 优先（页面写 Anything would be OK, Python preferred）
- 定位：剑桥 Sir David MacKay 的信息论课，对应教材 Information Theory, Inference, and Learning Algorithms 是信息论领域的经典著作；页面标注 R.I.P Prof. David MacKay。
- 作业/项目：每节课视频结尾留教材上的课后习题，没有独立 Project。
- 自学建议：本组里学时最短的一门，可作为信息论的第一门；教材电子版在课程网站免费下载，B 站有配套视频。
- 链接：http://www.inference.org.uk/mackay/itila/

### 1.5 Stanford EE364A: Convex Optimization

- 学校：Stanford
- 难度：★★★★★
- 学时：约 150 小时
- 先修：Python、微积分、线性代数、概率论、数值分析
- 语言：Python
- 定位：Stephen Boyd 的凸优化课，其教材 Convex Optimization 被众多名校采用；核心体验是同一个问题建模时一点细小的改动，求解难度就天壤之别，如何把方程建成「凸」的是一门艺术。
- 作业/项目：9 个 Python 编程作业，用 Boyd 团队开发的凸优化建模框架（支持 Python、Julia 等）解实际凸优化问题。
- 自学建议：先修要求最全的一门，建议在概率论与数值分析之后再上；重点不在推公式而在建模，作业要动手调模型。
- 链接：http://stanford.edu/class/ee364a/index.html

### 1.6 MIT18.330: Introduction to numerical analysis

- 学校：MIT
- 难度：★★★★★
- 学时：约 150 小时
- 先修：微积分、线性代数、概率论
- 语言：Julia
- 定位：数值分析入门，主题是用离散表示去估计和逼近数学上连续的概念；覆盖浮点表示、方程求解、线性代数、微积分、微分方程等领域的各类数值方法。
- 作业/项目：10 个 Julia 编程作业；课程设计者写了配套开源教材（fncbook.com），含丰富 Julia 实例。
- 自学建议：全程围绕三步反复练——如何建立估计、如何估计误差、如何用算法实现估计；要先会 Julia 基本用法。
- 链接：https://github.com/mitmath/18330
