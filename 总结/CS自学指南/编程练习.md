## 循环与边界

### 1.1 用 while 累加

**编程题**

1. 写一个 C 函数 `int sum_to(int n)`，返回 1 到 n 的和，不许用 for 循环。
- 语言: C
- 判定: 必须用 while 循环；不许用 for；不许调用现成的求和函数；n 小于等于 0 时返回 0；代码能编译通过。
- 提示: 循环变量从 1 走到 n，累加器先置 0，返回值是累加器。
- 踩坑场景: 循环里忘了 i++，程序死循环。

### 1.2 去重保序

**编程题**

2. 写一个 Python 函数 `dedup(nums)`，返回去掉重复元素后的列表，并保持元素第一次出现的顺序。
- 语言: Python
- 判定: 返回类型必须是 list；保持首次出现的顺序；不许用 set 直接转换（set 会丢顺序）；空列表返回空列表。
- 提示: 用一个已见过的集合判重，结果列表追加；或者用 dict.fromkeys 再转 list。
- 踩坑场景: 直接写 list(set(nums))，顺序被打乱。

### 1.3 反转字符串

**编程题**

3. 用 Java 写一个方法 `String reverse(String s)`，返回反转后的字符串。
- 语言: Java
- 判定: 不许调用 StringBuilder 或 StringBuffer 的 reverse 方法；参数为 null 时返回 null；空串返回空串；方法签名必须是 public static String reverse(String s)。
- 提示: 从后往前逐个字符拼接，或者转成 char 数组用双指针交换。

### 1.4 实现防抖

**编程题**

4. 用 JavaScript 实现 `debounce(fn, wait)`，返回一个包装后的函数。
- 语言: JavaScript
- 判定: 连续调用时只在最后一次调用后 wait 毫秒执行一次 fn；执行时保留调用时的 this 和全部参数；wait 毫秒内没有新调用才触发。
- 提示: 闭包里保存 timer，每次调用先 clearTimeout 再 setTimeout。
- 踩坑场景: 定时器 id 没保存到闭包外层，每次调用都是新定时器，最后执行了好几次。

### 1.5 指针交换

**编程题**

5. 用 C 写一个函数 `void swap(int *a, int *b)`，交换两个整数的值。
- 语言: C
- 判定: 两个参数必须是指针类型；函数内部通过解引用交换；调用 swap(&x, &y) 之后外部两个变量的值确实互换；不许用 C++ 的引用写法。
- 提示: 临时变量保存 *a，再给 *a 赋 *b，给 *b 赋临时变量。
- 踩坑场景: 写成 swap(int a, int b)，函数里交换的是副本，外面的值没变。
